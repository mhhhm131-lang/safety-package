الخطة بالاختصار

الخطوة ماذا نفعل المخرج الوقت
١ جدول plan_specializations جدول يحفظ التعديلات المحلية 15 دقيقة
٢ كود قراءة يختار (تخصيص vs أساسي) وظيفة تعيد النص الصحيح 20 دقيقة
٣ شاشة تحرير بسيطة نموذج يحفظ التعديل 20 دقيقة
٤ اختبار على المنشور النسخة المحدّثة تظهر 5 دقائق
المجموع ساعة واحدة

الخطوة الأولى: الجدول

① ماذا نفعل

إنشاء جدول واحد فقط يحفظ التخصيصات:

CREATE TABLE plan_specializations ( id INT PRIMARY KEY AUTO_INCREMENT, plan_id INT, -- معرّف الخطة (١-١٧) department_id INT, -- معرّف الفرع/الإدارة item_id INT, -- معرّف البند في الخطة value_key VARCHAR(100), -- اسم الحقل (responsible_person, location, إلخ) value TEXT, -- القيمة الجديدة created_at TIMESTAMP, updated_at TIMESTAMP, UNIQUE(plan_id, department_id, item_id, value_key) );

② المخرج

جدول موجود في قاعدة البيانات
Migration مُنفَّذة
يمكن إدراج صف اختبار والتحقق منه

③ قياس النجاح

شغّل هذا الاستعلام:

-- أدرج صف اختبار INSERT INTO plan_specializations (plan_id, department_id, item_id, value_key, value) VALUES (2, 5, 2, "responsible_person", "إسعاف خارجي 997"); -- اقرأ الصف SELECT * FROM plan_specializations WHERE plan_id=2 AND department_id=5; -- النتيجة: الصف يظهر مع القيمة الجديدة ✓

الخطوة الثانية: الكود

① ماذا نفعل

إضافة وظيفة واحدة في الـ service:

// app/Services/PlanService.php public function getItemValue( $planId, $departmentId, $itemId, $valueKey, $defaultValue ) { // ١. ابحث عن تخصيص $specialization = DB::table('plan_specializations') ->where('plan_id', $planId) ->where('department_id', $departmentId) ->where('item_id', $itemId) ->where('value_key', $valueKey) ->first(); // ٢. إذا وجدت → عودة القيمة الجديدة if ($specialization) { return $specialization->value; } // ٣. إلا → عودة الأساسي return $defaultValue; }

② المخرج

وظيفة تختار بين التخصيص والأساسي
تُستخدم في عرض الخطة

③ قياس النجاح

اختبر الوظيفة:

// الملز (department_id=1): لا تخصيص $result = $planService->getItemValue( 2, 1, 2, "responsible_person", "الطبيب أحمد" ); // النتيجة: "الطبيب أحمد" ✓ // القصيم (department_id=5): تخصيص موجود $result = $planService->getItemValue( 2, 5, 2, "responsible_person", "الطبيب أحمد" ); // النتيجة: "إسعاف خارجي 997" ✓

الخطوة الثالثة: الواجهة

① ماذا نفعل

إضافة نموذج تحرير بسيط على الصفحة الموجودة:

الزر والنموذج (HTML):

<button @click="editItem(itemId)">تعديل</button> <div v-if="editing[itemId]"> <input v-model="editValue" placeholder="القيمة الجديدة"> <button @click="save(itemId, editValue)">حفظ</button> </div>

API واحد (POST):

POST /api/plans/specializations { "plan_id": 2, "department_id": 5, "item_id": 2, "value_key": "responsible_person", "value": "إسعاف خارجي 997" }
