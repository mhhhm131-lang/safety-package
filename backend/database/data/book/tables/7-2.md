# جداول الفرع ٧-٢ — العمل المكتبي على الشاشات

---

## ER-02-01 — محطة العمل المكتبية غير المضبوطة (كرسي، مكتب، ارتفاع الشاشة، لوحة المفاتيح، الفأرة)
**الحالة:** **معتمد** (تفويض المستخدم ٢٠٢٦-٠٩-١١ — قرار ٣٢)

### الرأس

| الخلية | المحتوى |
|---|---|
| الكود | ER-02-01 |
| الصنف / الفرع | ٧ الإرجونومية / ٧-٢ العمل المكتبي على الشاشات |
| العنوان | محطة العمل المكتبية غير المضبوطة (كرسي، مكتب، ارتفاع الشاشة، لوحة المفاتيح، الفأرة) |
| الوصف | **المصدر:** محطة عمل الموظف: كرسي بلا ضبط للارتفاع والظهر أو مضبوط خطأ، مكتب مرتفع أو منخفض، شاشة أدنى أو أعلى من مستوى العين أو جانبية أو بعيدة، لوحة مفاتيح وفأرة بعيدتان أو على حافة المكتب، لا مسند للقدمين أو المعصم، وثائق بلا حامل، فتفرض وضعيات رقبة وكتف ومعصم مجهدة لساعات يومياً على سنوات. **التعرض:** كل الموظفين الإداريين والأكاديميين ومناوبي المركز، وهم أكبر فئة في المعهد. **الحدث المحتمل:** آلام الرقبة والكتف والظهر السفلي، متلازمة النفق الرسغي، إجهاد العين (الصنف ١ للإضاءة)، تراكمية على سنوات وتسبب غياباً وعجزاً جزئياً. **الموقع:** المكاتب (HZ-06)، مركز السلامة، مكاتب الاستقبال. |
| الخطورة | **٢ — بسيط** (مقترح): آلام مزمنة تُعالج ولا تعيق كلياً، لكنها واسعة الانتشار |
| الاحتمالية | **٤ — مرجح** (مقترح): أغلب المحطات غير مضبوطة والشكاوى شائعة جداً |
| الدرجة | **٨ — عالٍ** |
| المرجع القانوني | نظام العمل م١٢٢؛ ISO 9241-5 (تصميم محطة العمل) وHSE DSE Regulations كمرجع؛ مواصفات SASO للأثاث المكتبي؛ جدول الأمراض المهنية — التأمينات |
| الفائدة من التوثيق | أكثر خطر انتشاراً وأقلها كلفة في المعالجة (ضبط ما هو موجود)؛ التوثيق يعطي كل موظف قائمة ضبط ذاتي وتقييماً عند التعيين والنقل |
| قناة الاتصال | مركز السلامة (المناوب) — المنسق في المكان ومسؤول السلامة بالمعهد |

### الطبقة الاستباقية — قبل الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب | **معدات ومواد:** كراسٍ غير قابلة للضبط أو تالفة، شاشات بلا حامل ارتفاع، مكاتب بارتفاع واحد، حواسيب محمولة كجهاز رئيسي (ER-02-03). **تنظيمية:** لا تقييم للمحطة عند التعيين أو النقل، شراء أثاث بلا مواصفة إرجونومية، محطات مشتركة (ER-05-03). **تدريب وكفاءة:** الموظف لا يعرف الضبط الصحيح. **سلوكية:** الجلوس على حافة الكرسي، الشاشة جانبية للتلفزيون أو النافذة، الفأرة بعيدة. **بيئية:** إضاءة تفرض إمالة الرأس (الصنف ١) |
| العواقب والأضرار | الموظفون — **٢ بسيط** (الفئة الأكبر) · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — ١ طفيف · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — **٢ بسيط** (يحتاجون ضبطاً خاصاً) · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ٢ بسيط (غياب وإنتاجية) · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ١ طفيف |
| الإجراء الوقائي | (١) مواصفة محطة العمل **(بحسب ISO 9241-5 وHSE DSE)**: كرسي قابل لضبط الارتفاع والظهر والمساند، مكتب بارتفاع مناسب أو قابل للضبط، شاشة بحامل ارتفاع بحيث يكون أعلاها بمستوى العين وعلى مسافة ذراع، لوحة مفاتيح وفأرة منفصلتان أمام الجسم، مسند قدمين عند الحاجة، حامل وثائق؛ واعتمادها في الشراء. (٢) قائمة ضبط ذاتي مصوّرة لكل موظف (قدمان على الأرض، ركبتان بزاوية قائمة، ظهر مسنود، مرفقان بزاوية قائمة، شاشة أمام العين) وتدريب قصير. (٣) تقييم المحطة عند التعيين والنقل والشكوى بمسؤول السلامة أو من يدربه، وسجل. (٤) استبدال الكراسي التالفة وإضافة حوامل الشاشات بأثر رجعي بحسب الأولوية (الشكاوى أولاً). (٥) قناة بلاغ شاغل لآلام الرقبة والظهر والمعصم المرتبطة بالمكتب، وتسجيلها لدى الطبيب لرصد الأنماط. (٦) بند «محطات العمل: الكراسي والشاشات والشكاوى» في نموذج فحص HZ-06 |
| الإجراء التصحيحي | عند كرسي تالف أو غير قابل للضبط: استبدال خلال المهلة. عند شاشة منخفضة: حامل. عند شكوى: تقييم المحطة خلال أسبوع وضبطها. عند شراء غير مطابق: رفض |
| التقييم بعد الإجراءات | المواصفة والضبط الذاتي والتقييم تخفض الاحتمالية من ٤ إلى ٢؛ الخطورة تبقى ٢. الدرجة المتبقية ≈ ٤ (منخفض) |
| الجهة والشخص | ٢٠ مسؤول السلامة بالمعهد (المواصفة والقائمة والتقييم والنموذج) · ٢ مدير المرافق والصيانة (الشراء والاستبدال والحوامل) · ٤ طبيب المعهد (رصد الأنماط) · ١٢ الموظف (الضبط الذاتي) |

### الطبقة التشغيلية — أثناء العمل الطبيعي

| الخلية | المحتوى |
|---|---|
| الأسباب | **سلوكية:** موظف ينقل مكتبه ولا يعيد الضبط، يستخدم كرسي زميله، يضع الشاشة جانباً، يعمل على المحمول وحده. **معدات ومواد:** ذراع الكرسي تنكسر ويستمر. **تنظيمية:** موظف جديد بلا تقييم. **اتصال وإشراف:** الألم يُعزى للعمر أو النوم |
| العواقب والأضرار | الموظفون — **٢ بسيط** · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — ١ طفيف · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — **٢ بسيط** · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ٢ بسيط · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ١ طفيف |
| الإجراء الوقائي (الضوابط القائمة) | (١) الضبط الذاتي بالقائمة عند أي تغيير (نقل، كرسي جديد، شاشة جديدة). (٢) الجولة الأسبوعية للمنسق: كراسٍ تالفة، شاشات منخفضة أو جانبية، محمول بلا حامل. (٣) الموظف الجديد يُقيَّم في أسبوعه الأول. (٤) أي ألم رقبة أو معصم متكرر = بلاغ وتقييم المحطة. (٥) الفحص الشهري HZ-06 |
| الإجراء التصحيحي | عند كرسي تالف: بلاغ واستبدال. عند شاشة جانبية أو منخفضة: ضبط فوري. عند شكوى: تقييم وضبط وإحالة إن استمر |
| التقييم بعد الإجراءات | الضبط عند التغيير والجولة تُبقي الاحتمالية عند ٢؛ الخطورة تبقى ٢. الدرجة ≈ ٤ (منخفض) |
| الجهة والشخص | ١٢ الموظف (الضبط الذاتي والبلاغ) · ٨ المنسق في المكان (الجولة والفحص) · ٢٠ مسؤول السلامة بالمعهد (تقييم الجدد والشكاوى) |

### طبقة الاستجابة — عند وقوع الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب (ما يفاقم الحدث) | **تدريب وكفاءة:** الاستمرار بالوضعية نفسها بعد الألم، مسكنات بلا معالجة السبب. **تنظيمية:** لا تقييم للمحطة بعد الشكوى فيعود الألم. **اتصال وإشراف:** الطبيب يعالج ولا يُبلَّغ مسؤول السلامة عن النمط |
| العواقب والأضرار | الموظفون — **٢ بسيط** (المصاب) · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — ١ طفيف · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — **٢ بسيط** · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ٢ بسيط · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ١ طفيف |
| الإجراء الوقائي (تسلسل الاستجابة) | (١) **اكتشاف:** ألم مستمر أو خدر في الرقبة أو الكتف أو الظهر أو المعصم مرتبط بساعات العمل. (٢) **تدخل أولي:** استراحة من الشاشة، تمارين إطالة بسيطة، تعديل الوضعية بالقائمة. (٣) **إحالة:** الطبيب للتقييم والعلاج (علاج طبيعي، جبيرة معصم) وفحص المحطة من مسؤول السلامة خلال أسبوع. (٤) **تصعيد:** خدر مستمر أو ضعف قبضة ← إحالة للتخصص. (٥) **استعادة:** ضبط المحطة أو استبدال المعدات، عودة تدريجية، تسجيل كمرض مهني محتمل إن ثبت. (٦) الطبيب يبلغ مسؤول السلامة بالأنماط (مكاتب متكررة) لمعالجة جماعية |
| الإجراء التصحيحي | تقييم المحطة: ما الذي كان خطأً؟ ← ضبط أو استبدال ← تسجيل ← تعميم إن كان النمط متكرراً (مثل شاشات إدارة كاملة منخفضة) |
| التقييم بعد الإجراءات | الإحالة المبكرة وضبط المحطة يمنعان التحول لعجز فتبقى الخطورة ٢؛ الاحتمالية لا تتأثر. **الدرجة المتبقية للكتاب ≈ ٤ (منخفض) بعد الطبقات الثلاث** |
| الجهة والشخص | ٤ طبيب المعهد (التقييم والعلاج والأنماط) · ٢٠ مسؤول السلامة بالمعهد (فحص المحطة والمعالجة الجماعية) · ١٢ الموظف (البلاغ والاستراحات) · ٢ مدير المرافق والصيانة (الاستبدال) |

**خلايا فارغة:** لا شيء. **الأرقام:** ٢×٤=٨. أعلى أثر بين الفئات ٢ = الخطورة ٢.

## ER-02-02 — الجلوس المتواصل لساعات طويلة بلا حركة أمام الشاشات
**الحالة:** **معتمد** (تفويض المستخدم ٢٠٢٦-٠٩-١١ — قرار ٣٢)

### الرأس

| الخلية | المحتوى |
|---|---|
| الكود | ER-02-02 |
| الصنف / الفرع | ٧ الإرجونومية / ٧-٢ العمل المكتبي على الشاشات |
| العنوان | الجلوس المتواصل لساعات طويلة بلا حركة أمام الشاشات |
| الوصف | **المصدر:** طبيعة العمل المكتبي والمناوبة في مركز السلامة والاستقبال: جلوس ٦–٨ ساعات متواصلة بلا وقوف أو مشي، حتى مع محطة مضبوطة، فيضعف الدورة الدموية وتتيبس العضلات وتضغط الأقراص الفقرية باستمرار، ويرتبط الجلوس المطوّل بأمراض القلب والسكري والسمنة وجلطات الساق. **التعرض:** كل الموظفين الإداريين، ومناوبو المركز والاستقبال الذين لا يستطيعون مغادرة المكان، ومن يعمل ساعات إضافية. **الحدث المحتمل:** آلام ظهر ورقبة مزمنة، جلطة وريدية عميقة في الساق (نادرة لكن خطيرة)، وتفاقم الأمراض المزمنة على المدى الطويل. **الموقع:** المكاتب (HZ-06)، مركز السلامة، الاستقبال. |
| الخطورة | **٢ — بسيط** (مقترح): آلام مزمنة وأثر صحي طويل؛ الجلطة نادرة |
| الاحتمالية | **٤ — مرجح** (مقترح): الجلوس المتواصل هو الوضع الافتراضي لأغلب الموظفين |
| الدرجة | **٨ — عالٍ** |
| المرجع القانوني | نظام العمل م١٠١ (فترات الراحة) وم١٢٢؛ ISO 9241 وHSE DSE (فترات الراحة والتغيير) كمرجع؛ إرشادات وزارة الصحة (النشاط البدني والجلوس المطوّل)؛ ISO 45003 |
| الفائدة من التوثيق | المحطة المضبوطة لا تكفي إن لم يتحرك الموظف؛ التوثيق يفصل السكون عن الضبط ويعطي قاعدة الحركة الدورية وبديلاً للمناوب الذي لا يغادر |
| قناة الاتصال | مركز السلامة (المناوب) — مسؤول السلامة بالمعهد |

### الطبقة الاستباقية — قبل الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب | **تنظيمية:** لا فترات راحة قصيرة منظمة، مناوبة المركز والاستقبال بلا بديل للحركة (OR-02-03)، ثقافة «الجالس يعمل والواقف يتكاسل»، ساعات إضافية طويلة. **فنية/هندسية:** لا مكاتب قابلة للوقوف، الطابعة والماء بجوار المكتب فلا داعي للمشي. **سلوكية:** تناول الغداء على المكتب، عدم القيام، اجتماعات طويلة جالسة. **بيئية:** لا مساحة للمشي، حر يمنع الخروج |
| العواقب والأضرار | الموظفون — **٢ بسيط** · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — ١ طفيف · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — **٢ بسيط** (مرضى القلب والسكري والحوامل) · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ٢ بسيط · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ١ طفيف |
| الإجراء الوقائي | (١) قاعدة الحركة **(بحسب HSE DSE وإرشادات وزارة الصحة)**: استراحة قصيرة من الشاشة والجلوس كل ساعة تقريباً (وقوف، مشي، إطالة) وتذكير على الشاشة أو بتطبيق، وفترات الراحة النظامية تُؤخذ بعيداً عن المكتب. (٢) مكاتب قابلة للوقوف لمن يطلبها ولمناوبي المركز والاستقبال، وتوزيع الطابعات والبرادات ليتطلب الوصول إليها مشياً. (٣) للمناوب الذي لا يغادر: تناوب قصير مع زميل أو بديل للحركة، ومكتب قابل للوقوف، وتمارين في المكان. (٤) توعية: الجلوس المطوّل خطر صحي، اجتماعات قصيرة أو واقفة، الغداء بعيداً عن المكتب، ومشي في الممرات المكيفة. (٥) الفحص الدوري للموظفين يشمل سؤال الجلوس والنشاط (الطبيب). (٦) بند «مكاتب الوقوف والتذكير» في فحص HZ-06 |
| الإجراء التصحيحي | عند مناوب بلا بديل للحركة: ترتيب التناوب. عند شكوى متكررة: مكتب وقوف. عند ثقافة تمنع القيام: توعية للمديرين |
| التقييم بعد الإجراءات | قاعدة الحركة والتذكير والمكاتب تخفض الاحتمالية من ٤ إلى ٢؛ الخطورة تبقى ٢. الدرجة المتبقية ≈ ٤ (منخفض) |
| الجهة والشخص | ٢٠ مسؤول السلامة بالمعهد (القاعدة والتوعية) · ٤ طبيب المعهد (الفحص والتوعية الصحية) · ٢ مدير المرافق والصيانة (مكاتب الوقوف والتوزيع) · ٢١ مناوب مركز السلامة (التناوب) |

| الخلية | المحتوى |

| العواقب والأضرار | الموظفون — **٢ بسيط** · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — ١ طفيف · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — **٢ بسيط** · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ٢ بسيط · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ١ طفيف |
| الإجراء الوقائي (الضوابط القائمة) | (١) التذكير كل ساعة والقيام فعلاً دقيقتين. (٢) الراحة النظامية بعيداً عن المكتب. (٣) المناوب يتناوب مع زميله للحركة، ويستخدم مكتب الوقوف. (٤) في الذروة: الاستراحات لا تُلغى. (٥) المنسق يذكّر في الجولة ويبلغ عن ثقافة تمنع القيام |
| الإجراء التصحيحي | عند تجاهل مستمر: توعية فردية. عند مناوب بلا تناوب: ترتيب. عند شكوى: الطبيب وتقييم |
| التقييم بعد الإجراءات | التذكير والتناوب تُبقي الاحتمالية عند ٢؛ الخطورة تبقى ٢. الدرجة ≈ ٤ (منخفض) |

## ER-02-03 — العمل الطويل على الحاسب المحمول والأجهزة اللوحية بلا حامل أو لوحة خارجية
**الحالة:** **معتمد** (تفويض المستخدم ٢٠٢٦-٠٩-١١ — قرار ٣٢)

### الرأس

| الخلية | المحتوى |

| الكود | ER-02-03 |
