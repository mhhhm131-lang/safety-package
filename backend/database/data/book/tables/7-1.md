# جداول الفرع ٧-١ — المناولة اليدوية

---

## ER-01-01 — رفع وحمل الأثاث والمعدات الثقيلة عند تجهيز القاعات والفعاليات ونقل المكاتب
**الحالة:** **معتمد** (تفويض المستخدم ٢٠٢٦-٠٩-١١ — قرار ٣٢)

### الرأس

| الخلية | المحتوى |
|---|---|
| الكود | ER-01-01 |
| الصنف / الفرع | ٧ الإرجونومية / ٧-١ المناولة اليدوية |
| العنوان | رفع وحمل الأثاث والمعدات الثقيلة عند تجهيز القاعات والفعاليات ونقل المكاتب |
| الوصف | **المصدر:** طاولات ومقاعد ومنصات وشاشات وأجهزة عرض ومكبرات وخزائن ومكاتب تُرفع وتُحمل يدوياً عند تجهيز القاعات لكل فعالية وعند نقل المكاتب وإعادة التوزيع، بأحمال ثقيلة أو غير منتظمة أو بلا مقابض، لمسافات وعبر أدراج، بعدد عمال قليل وفي وقت ضيق، وبلا عربات أو معدات مساعدة. **التعرض:** عمال الخدمات والنظافة والمقاولون، وموظفو الفعاليات والمنسقون الذين يساعدون، والفنيون. **الحدث المحتمل:** إصابات الظهر (ديسك، شد عضلي) والكتف والركبة التراكمية والحادة، وهي أكثر الإصابات المهنية في الخدمات؛ سقوط الحمل على القدم في الصنف ٤. **الموقع:** القاعات وصالات الفعاليات (HZ-07)، المكاتب (HZ-06)، المخازن (HZ-08). |
| الخطورة | **٣ — متوسط** (مقترح): إصابة ظهر تحتاج علاجاً وغياباً وقد تصبح مزمنة |
| الاحتمالية | **٤ — مرجح** (مقترح): تجهيز شبه يومي للقاعات وأحمال ثقيلة بلا معدات؛ شكاوى الظهر شائعة |
| الدرجة | **١٢ — عالٍ** |
| المرجع القانوني | نظام العمل م١٢٢ ولائحته (حدود الأحمال)؛ ISO 11228-1 (الرفع والحمل: الحدود بحسب الوزن والمسافة والتكرار) وHSE L23/MAC كمرجع؛ جدول الأمراض المهنية — التأمينات الاجتماعية (اضطرابات الجهاز العضلي الهيكلي)؛ لائحة مسؤول السلامة (التدريب) |
| الفائدة من التوثيق | إصابة الظهر لا تُسجَّل كحادث ولا يُرى سببها؛ التوثيق يعطي التجهيز عربات ومعدات وقاعدة «اثنان لما فوق الحد» ويجعل الشكوى بلاغاً |
| قناة الاتصال | مركز السلامة (المناوب) — مدير المرافق والصيانة والمنسق في المكان |

### الطبقة الاستباقية — قبل الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب | **معدات ومواد:** لا عربات ولا رافعات يدوية ولا أحزمة حمل، أثاث ثقيل بلا عجلات أو مقابض، طاولات غير قابلة للطي. **تنظيمية:** تجهيز في وقت ضيق بعمال قلة، لا تقييم للمناولة، لا حد للوزن الفردي، المنسق يحمل بنفسه. **تدريب وكفاءة:** لا تدريب على الرفع الصحيح. **سلوكية:** رفع بالظهر لا بالساقين، التواء أثناء الحمل، حمل أثقل من الحد لتوفير رحلة. **فنية/هندسية:** أدراج بلا مصعد خدمة، ممرات ضيقة، عتبات. **بيئية:** حر يزيد الإجهاد |
| العواقب والأضرار | الموظفون — **٣ متوسط** (الخدمات والفعاليات) · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٣ متوسط** (الأكثر تعرضاً) · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ١ طفيف · الممتلكات والأنظمة — ٢ بسيط (تلف المعدات) · استمرارية الأعمال — ٢ بسيط (غياب العمال) · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٢ بسيط (إصابات عمل وتعويض) |
| الإجراء الوقائي | (١) تقييم المناولة لتجهيز القاعات ونقل المكاتب **(بحسب ISO 11228-1 وHSE MAC)**: جرد الأحمال المتكررة ووزنها، وتحديد ما يُحمل فردياً وما يحتاج اثنين أو معدة، بحدود الوزن والمسافة بحسب المعيار. (٢) معدات: عربات دفع بأنواعها (مسطحة، للمقاعد، للطاولات)، رافعة يدوية للثقيل، أحزمة حمل، ومقاعد وطاولات بعجلات وقابلة للطي عند الشراء، ومصعد خدمة أو مسار بلا أدراج للتجهيز. (٣) تنظيم: وقت كافٍ للتجهيز بعدد عمال مناسب، تخزين معدات القاعات قريباً منها، ومنع المنسقين والموظفين من الحمل الثقيل (يطلبون الخدمات). (٤) تدريب عمال الخدمات والمقاولين على الرفع الصحيح (الساقين، القرب من الجسم، لا التواء، الحمل الفريقي) بسجل، وشرطه في العقود. (٥) قناة بلاغ شاغل لآلام الظهر المرتبطة بالعمل، وتسجيلها لدى الطبيب. (٦) بند «المعدات والحدود والتدريب» في نموذج تجهيز القاعة وفحص HZ-07 |
| الإجراء التصحيحي | عند تجهيز بلا عربات أو بعمال أقل: تأجيل أو تعزيز. عند حمل فردي فوق الحد: إيقاف وتوفير المعدة أو الشريك. عند عمال غير مدربين: تدريب خلال شهر. عند أثاث بلا عجلات يُنقل كثيراً: استبدال أو تركيب عجلات |
| التقييم بعد الإجراءات | المعدات والحدود والتدريب تخفض الاحتمالية من ٤ إلى ٢؛ الخطورة تبقى ٣. الدرجة المتبقية ≈ ٦ (منخفض) |
| الجهة والشخص | ٢ مدير المرافق والصيانة (المعدات والأثاث والمصعد والعقود) · ٢٠ مسؤول السلامة بالمعهد (التقييم والتدريب والنموذج) · ٨ المنسق في المكان (التخطيط والوقت والعمال) · ٤ طبيب المعهد (تسجيل الشكاوى) |

### الطبقة التشغيلية — أثناء العمل الطبيعي

| الخلية | المحتوى |
|---|---|
| الأسباب | **سلوكية:** عامل يحمل طاولة وحده بدل انتظار زميله، يرفع بالظهر، يحمل عبر الدرج بدل المصعد، منسق يساعد بحمل شاشة. **تنظيمية:** فعالية مفاجئة تُجهَّز في ساعة، العربات في مخزن بعيد. **بيئية:** حر، ممر مزدحم. **اتصال وإشراف:** ألم الظهر يُكتم خوفاً على العمل |
| العواقب والأضرار | الموظفون — **٣ متوسط** · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٣ متوسط** · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ١ طفيف · الممتلكات والأنظمة — ٢ بسيط · استمرارية الأعمال — ٢ بسيط · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٢ بسيط |
| الإجراء الوقائي (الضوابط القائمة) | (١) العربات والمعدات تُستخدم في كل تجهيز، ومتاحة في مخزن القاعة. (٢) قاعدة «الثقيل باثنين أو بمعدة، لا تواء، الساقان لا الظهر» في كل مناولة، ومشرف الخدمات يراقب. (٣) التجهيز يُطلب بوقت كافٍ (بند تجهيز القاعة)، والمفاجئ يُعزَّز بعمال. (٤) المصعد للأثاث لا الدرج. (٥) أي ألم ظهر أو كتف بعد مناولة = بلاغ للطبيب وتخفيف مؤقت، لا كتمان. (٦) استراحات وماء في الحر (PH-01) |
| الإجراء التصحيحي | عند حمل فردي ثقيل: إيقاف وشريك. عند تجهيز بلا عربات: جلبها قبل الاستمرار. عند شكوى ألم: تخفيف وإحالة وتسجيل. عند تكرار الشكاوى في مهمة: إعادة تقييمها |
| التقييم بعد الإجراءات | الاستخدام الفعلي للمعدات والقاعدة تُبقي الاحتمالية عند ٢؛ الخطورة تبقى ٣. الدرجة ≈ ٦ (منخفض) |
| الجهة والشخص | مشرف الخدمات والمقاول (المراقبة والمعدات — دور نظامي خارج البطاقات) · ٨ المنسق في المكان (طلب التجهيز بوقت) · ١٢ الموظف (لا حمل ثقيل والبلاغ) · ٤ طبيب المعهد (الإحالة) |

### طبقة الاستجابة — عند وقوع الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب (ما يفاقم الحدث) | **تدريب وكفاءة:** العامل يواصل الحمل بعد الشعور بالألم الحاد، أو يحاول تعديل ظهره بنفسه، أو يُحمل بشكل خاطئ. **تنظيمية:** لا إحالة للطبيب واستمرار في العمل نفسه فيتحول لمزمن. **اتصال وإشراف:** العامل وحده أثناء الحمل |
| العواقب والأضرار | الموظفون — **٣ متوسط** (المصاب) · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٣ متوسط** · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ١ طفيف · الممتلكات والأنظمة — ٢ بسيط · استمرارية الأعمال — ٢ بسيط · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٢ بسيط |
| الإجراء الوقائي (تسلسل الاستجابة) | (١) **اكتشاف:** ألم حاد مفاجئ في الظهر أو الكتف أثناء الرفع، أو عجز عن الاستقامة أو الحركة، أو خدر في الساق. (٢) **تدخل أولي:** إيقاف الحمل فوراً وإنزاله بمساعدة، إجلاس أو إضجاع المصاب في وضع مريح، عدم محاولة «تعديل» الظهر أو تدليكه، كمادة باردة في الساعات الأولى. (٣) **إنذار:** المسعف عبر المركز، والطبيب. (٤) **تصعيد:** خدر أو ضعف في الساق أو فقدان التحكم أو ألم لا يحتمل ← **٩٩٧** ونقل بلا ثني للظهر (لوح)؛ غير ذلك ← غرفة الإسعاف والطبيب. (٥) **إسعاف:** راحة وتقييم الطبيب وإحالة للعلاج الطبيعي أو العظام. (٦) **استعادة:** عودة تدريجية بمهام خفيفة بتوصية الطبيب، تسجيل كإصابة عمل (والمقاول في سجله)، مراجعة المهمة |
| الإجراء التصحيحي | تحقيق: الحمل والمعدة والعدد والتدريب ← تصحيح المهمة ومساءلة المشرف إن أهمل ← تسجيل إصابة عمل ← تعميم |
| التقييم بعد الإجراءات | الإيقاف الفوري والإحالة والعودة التدريجية يمنعان التحول لإصابة مزمنة فتنخفض الخطورة الفعلية من ٣ إلى ٢؛ الاحتمالية لا تتأثر. **الدرجة المتبقية للكتاب ≈ ٤ (منخفض) بعد الطبقات الثلاث** |
| الجهة والشخص | ٩ المسعف في المكان (الإسعاف والتقييم) · مشرف الخدمات (الإيقاف والنداء) · ٤ طبيب المعهد (التقييم والإحالة والعودة) · ٢١ مناوب مركز السلامة (الإنذار) · ٢٠ مسؤول السلامة بالمعهد (التحقيق والتسجيل) |

**خلايا فارغة:** لا شيء. **الأرقام:** ٣×٤=١٢. أعلى أثر بين الفئات ٣ = الخطورة ٣.

## ER-01-02 — رفع صناديق الأرشيف والملفات والقرطاسية في المخازن والمكاتب
**الحالة:** **معتمد** (تفويض المستخدم ٢٠٢٦-٠٩-١١ — قرار ٣٢)

### الرأس

| الخلية | المحتوى |
|---|---|
| الكود | ER-01-02 |
| الصنف / الفرع | ٧ الإرجونومية / ٧-١ المناولة اليدوية |
| العنوان | رفع صناديق الأرشيف والملفات والقرطاسية في المخازن والمكاتب |
| الوصف | **المصدر:** صناديق الملفات (١٠–٢٠ كغم) وعلب الورق (١٢ كغم لكل ٥ رزم) وكراتين القرطاسية والمطبوعات تُرفع من الأرض إلى رفوف عالية وتُنزل منها وتُحمل بين المكاتب والمخازن يومياً، بأحمال متوسطة لكن متكررة ومن ارتفاعات سيئة (فوق الكتف أو تحت الركبة) وبالتواء عند وضعها على الرف. **التعرض:** موظفو الأرشيف والمخازن والسكرتارية وعمال الخدمات، ومعظمهم غير مدرَّبين. **الحدث المحتمل:** إصابة ظهر وكتف تراكمية من التكرار، وإصابة حادة عند رفع صندوق من رف عالٍ؛ سقوط الصندوق على الرأس في الصنف ٤. **الموقع:** الأرشيف والمخازن (HZ-08)، المكاتب (HZ-06). |
| الخطورة | **٣ — متوسط** (مقترح): إصابة تراكمية تحتاج علاجاً؛ أقل حدة من الأثاث الثقيل لكن أكثر تكراراً |
| الاحتمالية | **٤ — مرجح** (مقترح): مناولة يومية في الأرشيف والمخازن ومن رفوف عالية |
| الدرجة | **١٢ — عالٍ** |
| المرجع القانوني | نظام العمل م١٢٢؛ ISO 11228-1 (الرفع المتكرر وارتفاع البدء والانتهاء) وHSE L23 كمرجع؛ جدول الأمراض المهنية — التأمينات؛ لائحة مسؤول السلامة |
| الفائدة من التوثيق | الصندوق «خفيف» فلا يُحسب، والتكرار من رف عالٍ هو ما يصيب؛ التوثيق يضع الثقيل في الرفوف الوسطى وسلم الأرشيف والعربة، ويحدّ وزن الصندوق |
| قناة الاتصال | مركز السلامة (المناوب) — المنسق في المكان |

### الطبقة الاستباقية — قبل الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب | **فنية/هندسية:** رفوف عالية فوق الكتف ومنخفضة تحت الركبة للصناديق الثقيلة، ممرات ضيقة تفرض الالتواء (ER-05-01/02). **معدات ومواد:** صناديق كبيرة تُملأ فوق الحد، بلا مقابض، لا عربات ولا سلالم أرشيف بمنصة. **تنظيمية:** لا حد لوزن الصندوق، لا قاعدة لتوزيع الرفوف، الأرشيف يُنقل دفعة واحدة في نهاية العام. **تدريب وكفاءة:** موظفون إداريون بلا تدريب مناولة. **سلوكية:** حمل صندوقين معاً، الرفع بالظهر، رمي الصندوق على الرف بالتواء |
| العواقب والأضرار | الموظفون — **٣ متوسط** (الأرشيف والمخازن والسكرتارية) · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٣ متوسط** (الخدمات) · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ٢ بسيط · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ٢ بسيط · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٢ بسيط |
| الإجراء الوقائي | (١) قاعدة التخزين الإرجونومية **(بحسب ISO 11228-1)**: الصناديق الثقيلة والمتكررة في الرفوف بين الركبة والكتف، الخفيفة والنادرة أعلى وأسفل، وحد أقصى لوزن الصندوق (يُحدد بحسب المعيار ويُكتب على الصندوق) وصناديق بمقابض. (٢) معدات: عربات في كل أرشيف ومخزن ومكتب مركزي، سلالم أرشيف بمنصة للرفوف العليا (ME-03-01)، ورفوف قابلة لإعادة الضبط. (٣) الرقمنة وإتلاف المنتهي لتقليل الحجم (FI-05-01)، وجدولة نقل الأرشيف على أيام لا دفعة. (٤) تدريب موظفي الأرشيف والمخازن والسكرتارية على الرفع (صندوق واحد، قريب من الجسم، لا التواء، تحريك القدمين). (٥) قناة البلاغ للألم المرتبط بالعمل. (٦) بند «توزيع الرفوف ووزن الصناديق والعربات والسلم» في نموذج فحص HZ-08 والمكاتب |
| الإجراء التصحيحي | عند ثقيل في رف عالٍ أو منخفض: إعادة توزيع خلال المهلة. عند صناديق فوق الحد: تقسيم. عند غياب العربة أو السلم: توفير. عند موظفين غير مدربين: تدريب |
| التقييم بعد الإجراءات | التوزيع والحد والمعدات تخفض الاحتمالية من ٤ إلى ٢؛ الخطورة تبقى ٣. الدرجة المتبقية ≈ ٦ (منخفض) |
| الجهة والشخص | ٢ مدير المرافق والصيانة (الرفوف والعربات والسلالم) · ٢٠ مسؤول السلامة بالمعهد (القاعدة والتدريب والنموذج) · أمين المخازن والأرشيف (التوزيع والحد) · إدارة الوثائق (الرقمنة والجدولة — دور نظامي خارج البطاقات) |

### الطبقة التشغيلية — أثناء العمل الطبيعي

| الخلية | المحتوى |

| الأسباب | **معدات ومواد:** عجلات صغيرة أو صلبة أو تالفة، مقابض منخفضة أو غائبة، عربات بلا مكابح، حاويات ثقيلة جداً. **فنية/هندسية:** منحدرات أشد من الكود، عتبات أبواب، سجاد سميك، أرضيات خشنة، أبواب ثقيلة تُفتح باليد أثناء الدفع. **صيانة وتشغيل:** لا صيانة للعجلات، عربات مثقلة. **تنظيمية:** لا حد للحمل، مسار العربات عبر الأدراج. **سلوكية:** سحب بدل الدفع، دفع عربة تحجب الرؤية، النزول أمام العربة على المنحدر |
| العواقب والأضرار | الموظفون — ٢ بسيط · المتدربون والزوار — ٢ بسيط (انفلات عربة) · المقاولون وعمالهم — **٣ متوسط** (النظافة والخدمات والمطاعم) · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ٢ بسيط · الممتلكات والأنظمة — ٢ بسيط · استمرارية الأعمال — ١ طفيف · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٢ بسيط |
| الإجراء الوقائي | (١) مواصفة العربات والحاويات **(بحسب ISO 11228-2)**: عجلات كبيرة ناعمة دوارة، مقابض بارتفاع مناسب، مكابح، حد حمل معلَّم، وصيانة دورية للعجلات والمحامل. (٢) المسارات: إزالة العتبات أو منحدرات صغيرة عندها، منحدرات بميل الكود **(كود الوصول الشامل)** وأسطح غير زلقة، أبواب آلية أو بمثبت على مسارات العربات، وتجنب السجاد السميك في الممرات الخدمية. (٣) قاعدة: الدفع لا السحب، بيدين، الرؤية فوق الحمل، على المنحدر الحاد عربة ثقيلة باثنين أحدهما خلفها والآخر أمامها بمكابح، ولا عربة على الدرج. (٤) حاويات النفايات الكبيرة بمواقع لا تحتاج منحدرات أو بجرار كهربائي صغير. (٥) تدريب العمال، وشرط المواصفة والصيانة في عقود النظافة والتشغيل. (٦) بند «العجلات والمكابح والحد والمسارات» في نماذج فحص HZ-05/HZ-08 والممرات |
| الإجراء التصحيحي | عند عربة بعجلات تالفة: إصلاح أو سحب من الخدمة. عند عتبة على مسار عربات: منحدر خلال المهلة. عند حاوية ثقيلة على منحدر حاد: نقل موقعها أو جرار. عند سحب أو حمل زائد: تذكير |
| التقييم بعد الإجراءات | المواصفة والمسارات والقاعدة تخفض الاحتمالية من ٣ إلى ١؛ الخطورة تبقى ٣. الدرجة المتبقية ≈ ٣ (منخفض) |
| الجهة والشخص | ٢ مدير المرافق والصيانة (المواصفة والمسارات والمنحدرات والعقود) · ٢٠ مسؤول السلامة بالمعهد (القاعدة والتدريب والنماذج) · مشرف النظافة والمطعم (الصيانة والتطبيق — دور نظامي خارج البطاقات) |

### الطبقة التشغيلية — أثناء العمل الطبيعي

| الخلية | المحتوى |
|---|---|
| الأسباب | **سلوكية:** عامل يسحب العربة الثقيلة وراءه، يملؤها فوق الحد لتوفير رحلة، ينزل المنحدر أمامها. **صيانة وتشغيل:** عجلة تتعطل ويستمر الاستخدام. **بيئية:** منحدر مبلل. **اتصال وإشراف:** العربة التالفة لا تُبلَّغ |
| العواقب والأضرار | الموظفون — ٢ بسيط · المتدربون والزوار — ٢ بسيط · المقاولون وعمالهم — **٣ متوسط** · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ٢ بسيط · الممتلكات والأنظمة — ٢ بسيط · استمرارية الأعمال — ١ طفيف · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٢ بسيط |
| الإجراء الوقائي (الضوابط القائمة) | (١) فحص العربة قبل الاستخدام (عجلات، مكابح) وسحب التالفة. (٢) الدفع بيدين ضمن الحد، والثقيل على المنحدر باثنين. (٣) المسارات المعتمدة (بلا درج وبلا عتبات) فقط. (٤) الفحص الشهري: العربات والحاويات والمنحدرات. (٥) الألم أو انفلات عربة بلا إصابة = بلاغ وحدث وشيك |
| الإجراء التصحيحي | عند عربة تالفة مستخدمة: سحب وإصلاح. عند سحب أو حمل زائد: تذكير. عند انفلات: تحقيق وتصحيح المسار أو المكابح |
| التقييم بعد الإجراءات | الفحص قبل الاستخدام والقاعدة تُبقي الاحتمالية عند ١؛ الخطورة تبقى ٣. الدرجة ≈ ٣ (منخفض) |
| الجهة والشخص | العامل ومشرفه (الفحص والقاعدة) · ٨ المنسق في المكان (الفحص الشهري) · ٢ مدير المرافق والصيانة (الإصلاح) |

### طبقة الاستجابة — عند وقوع الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب (ما يفاقم الحدث) | **تدريب وكفاءة:** محاولة إيقاف عربة منفلتة بالجسم على المنحدر. **بيئية:** عربة ثقيلة تنفلت نحو مشاة أو مركبات. **تنظيمية:** لا إحالة لإصابة الكتف فتصبح مزمنة |
| العواقب والأضرار | الموظفون — ٢ بسيط · المتدربون والزوار — ٢ بسيط · المقاولون وعمالهم — **٣ متوسط** (المصاب) · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ٢ بسيط · الممتلكات والأنظمة — ٢ بسيط · استمرارية الأعمال — ١ طفيف · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٢ بسيط |
| الإجراء الوقائي (تسلسل الاستجابة) | (١) **اكتشاف:** ألم حاد في الكتف أو الظهر أثناء الدفع، أو عربة تنفلت على منحدر. (٢) **تدخل أولي:** انفلات: الابتعاد عن مسارها والتحذير بالصوت، لا إيقاف بالجسم، وتأمينها بعد توقفها؛ إصابة: ترك العربة، راحة، كمادة باردة. (٣) **إنذار:** المسعف عبر المركز، وإصابة صدم ← الصنف ٤. (٤) **تصعيد:** خدر أو ضعف أو صدم ← **٩٩٧**؛ غير ذلك ← الطبيب. (٥) **إسعاف:** التقييم والإحالة. (٦) **استعادة:** عودة تدريجية، تسجيل، فحص العربة والمسار |
| الإجراء التصحيحي | تحقيق: العربة والحمل والمسار ← إصلاح ومساءلة المقاول إن أهمل ← تسجيل ← تعميم |
| التقييم بعد الإجراءات | الابتعاد عن المنفلتة والإحالة المبكرة يخفضان الخطورة الفعلية من ٣ إلى ٢؛ الاحتمالية لا تتأثر. **الدرجة المتبقية للكتاب ≈ ٢ (منخفض) بعد الطبقات الثلاث** |
| الجهة والشخص | ٩ المسعف في المكان (الإسعاف) · مشرف العامل (الإيقاف والإبلاغ) · ٤ طبيب المعهد (التقييم) · ٢١ مناوب مركز السلامة (الإنذار) · ٢٠ مسؤول السلامة بالمعهد (التحقيق) |

**خلايا فارغة:** لا شيء. **الأرقام:** ٣×٣=٩. أعلى أثر بين الفئات ٣ = الخطورة ٣.
