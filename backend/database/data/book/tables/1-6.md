# جداول الفرع ١-٦ — التهوية وجودة الهواء والرطوبة

## PH-06-01 — ضعف تجديد الهواء وتراكم ثاني أكسيد الكربون في القاعات والمكاتب المزدحمة
**الحالة:** **معتمد** (تفويض المستخدم ٢٠٢٦-٠٩-١١ — قرار ٣٢)

### الرأس

| الخلية | المحتوى |
|---|---|
| الكود | PH-06-01 |
| الصنف / الفرع | ١ الفيزيائية — عوامل البيئة / ١-٦ التهوية وجودة الهواء والرطوبة |
| العنوان | ضعف تجديد الهواء وتراكم ثاني أكسيد الكربون في القاعات والمكاتب المزدحمة |
| الوصف | **المصدر:** تكييف يعيد تدوير الهواء بلا هواء خارجي كافٍ: مجاري هواء خارجي مغلقة أو مسدودة، فلاتر متشبعة، قاعات تُشغَل فوق سعتها التصميمية، مكاتب مفتوحة مكتظة، وغرف اجتماعات مغلقة ساعات. **التعرض:** المتدربون والمحاضرون في القاعات لساعات متصلة، الموظفون في المكاتب المفتوحة، الحضور في الفعاليات الكبيرة. **الحدث المحتمل:** ارتفاع تركيز ثاني أكسيد الكربون فوق ١٠٠٠ جزء في المليون ومعه نعاس وصداع وانخفاض تركيز وشكوى «هواء خانق»، وتراكم روائح وملوثات داخلية وانتقال العدوى التنفسية بسهولة أكبر. **الموقع:** القاعات التدريبية (HZ-07) والمكاتب الإدارية (HZ-06) وغرف الاجتماعات. |
| الخطورة | **٢ — بسيط** (مقترح): أعراض خفيفة تزول بالتهوية؛ التركيزات الخطرة لا تُبلغ في مبنى مكيّف |
| الاحتمالية | **٤ — مرجح** (مقترح): قاعات ممتلئة يومياً وتكييف يعتمد إعادة التدوير توفيراً للطاقة |
| الدرجة | **٨ — عالٍ** |
| المرجع القانوني | نظام العمل م١٢١ (تهوية أماكن العمل)؛ ASHRAE 62.1 (معدلات الهواء الخارجي للإشغال: قاعات التعليم ونسبة CO₂)؛ ISO 17772؛ كود البناء السعودي الميكانيكي SBC 501؛ إرشادات هيئة الصحة العامة لتهوية الأماكن المغلقة |
| الفائدة من التوثيق | «الهواء الخانق» أكثر شكوى لا تُقاس؛ التوثيق يحوّلها إلى قياس CO₂ ومعدل هواء خارجي وسعة قاعة، ويربطها بانتقال العدوى الذي يمس الصنف الثالث |
| قناة الاتصال | مركز السلامة (المناوب) — مدير المرافق والصيانة |

### الطبقة الاستباقية — قبل الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب | **فنية/هندسية:** مجاري الهواء الخارجي مغلقة أو غير موجودة في بعض الوحدات، تصميم لا يحسب سعة القاعات الحالية. **صيانة وتشغيل:** فلاتر لا تُستبدل، مراوح هواء خارجي معطلة. **تنظيمية:** لا سعة قصوى معلنة للقاعات ولا قياس لجودة الهواء. **بيئية:** ازدحام الفعاليات والامتحانات فوق السعة. **سلوكية:** إغلاق فتحات الهواء لتقليل البرد |
| العواقب والأضرار | الموظفون — **٢ بسيط** (المكاتب المفتوحة) · المتدربون والزوار — **٢ بسيط** (القاعات الممتلئة) · المقاولون وعمالهم — ١ طفيف · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ٢ بسيط (الربو وأمراض التنفس) · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ٢ بسيط (انخفاض جودة التدريب) · السمعة — ٢ بسيط / محلي (شكاوى المتدربين) · الخسائر المالية والقانونية — ١ طفيف |
| الإجراء الوقائي | (١) التحقق من معدل الهواء الخارجي لكل وحدة تكييف تخدم قاعة أو مكتباً مفتوحاً وضبطه على المعدل المرجعي **(من ASHRAE 62.1 بحسب الإشغال)**. (٢) سعة قصوى معلنة على باب كل قاعة تُحسب من التهوية لا من المقاعد وحدها. (٣) مقاييس CO₂ في القاعات الكبيرة والمكاتب المفتوحة بمؤشر ملوّن. (٤) جدول استبدال الفلاتر وصيانة مراوح الهواء الخارجي في الصيانة الوقائية. (٥) قياس دوري لجودة الهواء ضمن الفحص نصف السنوي. (٦) بند التهوية في عقد صيانة التكييف |
| الإجراء التصحيحي | عند قراءة CO₂ فوق الحد المرجعي في قاعة أو مجرى هواء خارجي مغلق: بلاغ فحص للمرافق بمهلة، وتقليل إشغال القاعة أو فترات تهوية حتى المعالجة. عند فلاتر متشبعة: استبدال خلال أسبوع |
| التقييم بعد الإجراءات | معدل الهواء الخارجي والسعة المعلنة يخفضان الاحتمالية من ٤ إلى ٢؛ الخطورة تبقى ٢. الدرجة المتبقية ≈ ٤ (منخفض) |
| الجهة والشخص | ٢ مدير المرافق والصيانة (المعدل والفلاتر والمقاييس) · مدير الإدارة المشغّلة للقاعات (السعة والجدولة) · ٢٠ مسؤول السلامة بالمعهد (القياس الدوري والمرجع) |

### الطبقة التشغيلية — أثناء العمل الطبيعي

| الخلية | المحتوى |
|---|---|
| الأسباب | **بيئية:** فعالية أو امتحان بحضور فوق السعة، أبواب مغلقة ساعات. **صيانة وتشغيل:** مروحة هواء خارجي تتعطل، فلتر يتشبع في موسم غبار. **سلوكية:** إغلاق فتحات التهوية، جلسة طويلة بلا استراحة. **اتصال وإشراف:** مقياس CO₂ أحمر ولا أحد يتصرف |
| العواقب والأضرار | الموظفون — **٢ بسيط** · المتدربون والزوار — **٢ بسيط** · المقاولون وعمالهم — ١ طفيف · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ٢ بسيط · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ٢ بسيط · السمعة — ٢ بسيط / محلي · الخسائر المالية والقانونية — ١ طفيف |
| الإجراء الوقائي (الضوابط القائمة) | (١) الالتزام بالسعة المعلنة عند جدولة القاعات. (٢) المحاضر يراقب مؤشر CO₂ ويفتح استراحة تهوية إذا احمرّ. (٣) استراحة كل ساعتين في الجلسات الطويلة مع فتح الأبواب. (٤) بند «التهوية وجودة الهواء» في جولة تفقّد القاعات. (٥) الإبلاغ عن الهواء الخانق كبلاغ شاغل عادي. (٦) استبدال الفلاتر المبكر في مواسم الغبار |
| الإجراء التصحيحي | عند مؤشر أحمر: تهوية فورية وتقليل الإشغال وبلاغ للمرافق إن تكرر. عند تكرار الشكوى من قاعة: قياس معدل الهواء الخارجي ومعالجة الوحدة |
| التقييم بعد الإجراءات | السعة والمؤشر والاستراحات تُبقي الاحتمالية عند ٢ والأعراض عابرة فتبقى الخطورة ٢. الدرجة ≈ ٤ (منخفض) |
| الجهة والشخص | ٦ المحاضر (المؤشر والاستراحة) · ٨ المنسق في المكان (الجولة) · ١٧ فني التكييف ونظام الدخان (الفلاتر والمراوح) · مدير الإدارة المشغّلة (الجدولة) |

### طبقة الاستجابة — عند وقوع الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب (ما يفاقم الحدث) | **تنظيمية:** استمرار الجلسة رغم الأعراض لضيق الوقت. **اتصال وإشراف:** الشكوى تُقال ولا تُبلَّغ. **صيانة وتشغيل:** الوحدة معطلة أياماً بلا علم أحد |
| العواقب والأضرار | الموظفون — **٢ بسيط** · المتدربون والزوار — **٢ بسيط** (إغماء نادر من الاختناق والحر) · المقاولون وعمالهم — ١ طفيف · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ٢ بسيط · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ٢ بسيط · السمعة — ٢ بسيط / محلي · الخسائر المالية والقانونية — ١ طفيف |
| الإجراء الوقائي (تسلسل الاستجابة) | (١) **اكتشاف:** مؤشر أحمر أو أعراض جماعية (صداع، نعاس) أو إغماء. (٢) **تدخل أولي:** فتح الأبواب والنوافذ وإيقاف الجلسة وإخراج الحضور إلى مكان مهوّى، وإسعاف من أُغمي عليه. (٣) **إنذار:** إبلاغ المركز والمسعف الأولي وفني التكييف. (٤) **تصعيد:** إغماء لا يفيق أو أعراض شديدة ← الطبيب أو **٩٩٧**؛ وإن اشتُبه بملوث غير CO₂ (غاز، دخان) يُطبَّق جدول الصنف الثاني. (٥) **احتواء:** إغلاق القاعة حتى فحص الوحدة. (٦) **استعادة:** قياس CO₂ قبل إعادة الإشغال |
| الإجراء التصحيحي | تحقيق: معدل الهواء الخارجي والإشغال وحالة الوحدة ← إصلاح وتعديل السعة ← تعميم على القاعات المخدومة بالوحدة نفسها |
| التقييم بعد الإجراءات | التهوية الفورية وإخراج الحضور يُبقيان الضرر عابراً فتبقى الخطورة ٢؛ الاحتمالية لا تتأثر. **الدرجة المتبقية للكتاب ≈ ٤ (منخفض) بعد الطبقات الثلاث** |
| الجهة والشخص | ٦ المحاضر (إيقاف الجلسة والتهوية) · ٩ المسعف في المكان (التدخل) · ٢١ مناوب مركز السلامة (الإنذار والتصعيد) · ١٧ فني التكييف ونظام الدخان (فحص الوحدة) |

**خلايا فارغة:** لا شيء. **الأرقام:** ٢×٤=٨. أعلى أثر بين الفئات ٢ = الخطورة ٢.

## PH-06-02 — اختلال الرطوبة (عالية مع تكاثف في الغرف الفنية ودورات المياه، أو منخفضة من التكييف)
**الحالة:** **معتمد** (تفويض المستخدم ٢٠٢٦-٠٩-١١ — قرار ٣٢)

### الرأس

| الخلية | المحتوى |
|---|---|
| الكود | PH-06-02 |
| الصنف / الفرع | ١ الفيزيائية — عوامل البيئة / ١-٦ التهوية وجودة الهواء والرطوبة |
| العنوان | اختلال الرطوبة (عالية مع تكاثف في الغرف الفنية ودورات المياه، أو منخفضة من التكييف) |
| الوصف | **المصدر:** رطوبة عالية وتكاثف في الغرف الفنية والقبو ودورات المياه وغرف المبردات بسبب تسربات ومجارٍ باردة وشفاطات معطلة؛ ورطوبة منخفضة جداً في المكاتب والقاعات من تكييف مستمر في مناخ جاف. **التعرض:** الفنيون وعمال النظافة في الأماكن الرطبة، وكل الشاغلين في الأماكن الجافة. **الحدث المحتمل:** في الرطوبة العالية: أرضيات مبللة تُزلق (سببٌ لخطر الصنف الرابع)، تآكل وتماس في اللوحات (سببٌ للصنف الخامس)، وبيئة لنمو العفن (الصنف الثالث)؛ في الرطوبة المنخفضة: جفاف العين والجلد والأنف وتهيج الحلق وكهرباء ساكنة تزعج وتؤذي الأجهزة. **الموقع:** القبو والغرف الفنية (HZ-01، HZ-02، HZ-03)، دورات المياه، المكاتب والقاعات (HZ-06، HZ-07). |
| الخطورة | **٢ — بسيط** (مقترح): الضرر المباشر للرطوبة نفسها خفيف؛ ما تُسببه (انزلاق، تماس، عفن) مصنّف في أصنافه |
| الاحتمالية | **٣ — ممكن** (مقترح): تكاثف موسمي في الغرف الفنية وجفاف مستمر في المكاتب؛ ليس يومياً في كل مكان |
| الدرجة | **٦ — منخفض** |
| المرجع القانوني | نظام العمل م١٢١؛ ASHRAE 55 و62.1 (نطاق الرطوبة النسبية ٣٠–٦٠٪)؛ ISO 7730؛ SBC 501 |
| الفائدة من التوثيق | الرطوبة سبب صامت لثلاثة أخطار في أصناف أخرى (الانزلاق، التماس، العفن)؛ توثيقها هنا يعطيها ضابطاً واحداً (القياس والتصريف والشفط) بدل معالجة نتائجها الثلاث كلٌّ على حدة |
| قناة الاتصال | مركز السلامة (المناوب) — مدير المرافق والصيانة |

### الطبقة الاستباقية — قبل الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب | **فنية/هندسية:** مجارٍ ومواسير باردة بلا عزل فتتكاثف، شفاطات دورات المياه والغرف الفنية معطلة أو ناقصة، تصريف تكاثف وحدات التكييف مسدود، لا ترطيب في المكاتب. **صيانة وتشغيل:** تسربات مياه مزمنة، مصارف مسدودة. **تنظيمية:** لا قياس للرطوبة ولا نطاق معتمد. **بيئية:** مناخ جاف جداً وتكييف مستمر |
| العواقب والأضرار | الموظفون — **٢ بسيط** (الفنيون والمكاتب) · المتدربون والزوار — ٢ بسيط (الجفاف في القاعات) · المقاولون وعمالهم — ٢ بسيط (النظافة والصيانة) · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ٢ بسيط (الربو والحساسية) · الممتلكات والأنظمة — **٢ بسيط** (تآكل وتلف الأجهزة والأثاث) · استمرارية الأعمال — ١ طفيف · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ١ طفيف |
| الإجراء الوقائي | (١) اعتماد نطاق رطوبة مرجعي **(من ASHRAE 55: ٣٠–٦٠٪)** وقياس أولي للغرف الفنية والقبو ودورات المياه والقاعات. (٢) عزل المواسير الباردة، وتأكيد شفاطات دورات المياه والغرف الفنية وتصريف التكاثف في الصيانة الوقائية. (٣) معالجة التسربات المزمنة كبلاغات فحص لا كأمر واقع. (٤) ترطيب موضعي أو ضبط التكييف في المكاتب الجافة إن تجاوز الجفاف النطاق. (٥) أرضيات مانعة للانزلاق في الأماكن الرطبة بطبيعتها. (٦) بند الرطوبة في عقد صيانة التكييف والسباكة |
| الإجراء التصحيحي | عند قياس خارج النطاق أو تكاثف أو تسرب في الجولة: بلاغ فحص للمرافق بمهلة، ووسم الأرضية المبللة حتى المعالجة. عند شفاط معطل: إصلاح خلال أسبوع |
| التقييم بعد الإجراءات | العزل والشفط والتصريف تخفض الاحتمالية من ٣ إلى ١؛ الخطورة تبقى ٢. الدرجة المتبقية ≈ ٢ (منخفض) |
| الجهة والشخص | ٢ مدير المرافق والصيانة (النطاق والعزل والشفاطات والتسربات) · ١٧ فني التكييف ونظام الدخان (التصريف والضبط) · ٢٠ مسؤول السلامة بالمعهد (القياس الدوري) |

| العواقب والأضرار | الموظفون — **٢ بسيط** · المتدربون والزوار — ٢ بسيط · المقاولون وعمالهم — ٢ بسيط · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ٢ بسيط · الممتلكات والأنظمة — **٢ بسيط** · استمرارية الأعمال — ١ طفيف · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ١ طفيف |

| الأسباب (ما يفاقم الحدث) | **صيانة وتشغيل:** ماء متجمع قرب لوحة كهربائية أو على درج. **تنظيمية:** لا أحد يملك إيقاف مصدر الماء. **اتصال وإشراف:** الفيض ليلاً بلا جولة |
| العواقب والأضرار | الموظفون — **٢ بسيط** · المتدربون والزوار — ٢ بسيط · المقاولون وعمالهم — ٢ بسيط · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ٢ بسيط · الممتلكات والأنظمة — **٢ بسيط** (أجهزة وأثاث) · استمرارية الأعمال — ١ طفيف · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ١ طفيف |
| الإجراء الوقائي (تسلسل الاستجابة) | (١) **اكتشاف:** تجمع ماء أو تكاثف غزير أو فيض، بالجولة أو ببلاغ. (٢) **إيقاف المصدر:** إغلاق صمام الماء أو إيقاف الوحدة المسببة، وفصل الكهرباء عن اللوحة القريبة إن وصلها الماء (بتسلسل الصنف الخامس). (٣) **تدخل أولي:** وسم المنطقة، تجفيف، إبعاد الأجهزة والأثاث. (٤) **إنذار:** إبلاغ المركز وفني التكييف أو السباكة. (٥) **احتواء:** إغلاق المكان حتى الجفاف والفحص. (٦) **استعادة:** فحص العفن بعد أسبوع من أي غمر |
| الإجراء التصحيحي | تحقيق: المصدر وسبب تأخر الاكتشاف ← إصلاح جذري (عزل، شفاط، تصريف) ← إضافة الموقع إلى الفحص الدوري |
| التقييم بعد الإجراءات | إيقاف المصدر والتجفيف السريع يمنعان الانزلاق والتماس والعفن فتبقى الخطورة ٢؛ الاحتمالية لا تتأثر. **الدرجة المتبقية للكتاب ≈ ٢ (منخفض) بعد الطبقات الثلاث** |
| الجهة والشخص | ٢١ مناوب مركز السلامة (الإنذار) · ١٧ فني التكييف ونظام الدخان أو فني السباكة (إيقاف المصدر) · ١٩ فني الكهرباء (فصل اللوحة) · ٨ المنسق في المكان (الوسم والاحتواء) |

**خلايا فارغة:** لا شيء. **الأرقام:** ٢×٣=٦. أعلى أثر بين الفئات ٢ = الخطورة ٢.
