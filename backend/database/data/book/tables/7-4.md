# جداول الفرع ٧-٤ — الحركات المتكررة والقوة اليدوية

## ER-04-01 — الحركات المتكررة في تحضير الطعام والتقطيع والغسيل في المطابخ
**الحالة:** **معتمد** (تفويض المستخدم ٢٠٢٦-٠٩-١١ — قرار ٣٢)

### الرأس

| الخلية | المحتوى |
|---|---|
| الكود | ER-04-01 |
| الصنف / الفرع | ٧ الإرجونومية / ٧-٤ الحركات المتكررة والقوة اليدوية |
| العنوان | الحركات المتكررة في تحضير الطعام والتقطيع والغسيل في المطابخ |
| الوصف | **المصدر:** تقطيع الخضار واللحوم بالسكين آلاف المرات في الوردية، تقليب القدور الكبيرة، عجن وفرد، تنظيف الصحون والأواني بالفرك، وتعبئة الوجبات، بحركات سريعة متكررة للمعصم والأصابع والكتف على طاولات بارتفاع واحد لا يناسب الجميع وبأدوات كليلة تحتاج قوة أكبر. **التعرض:** عمال المطابخ (طهاة ومساعدون وعمال غسيل). **الحدث المحتمل:** متلازمة النفق الرسغي، التهاب أوتار المعصم والمرفق (مرفق التنس) والكتف، تراكمية تعطل اليد. **الموقع:** المطابخ (HZ-05). |
| الخطورة | **٣ — متوسط** (مقترح): النفق الرسغي والتهاب الأوتار يحتاجان علاجاً طويلاً وقد يحتاجان جراحة |
| الاحتمالية | **٤ — مرجح** (مقترح): التكرار العالي هو طبيعة العمل ومع أدوات وطاولات غير مناسبة |
| الدرجة | **١٢ — عالٍ** |
| المرجع القانوني | نظام العمل م١٢٢؛ ISO 11228-3 (المهام المتكررة للأطراف العليا) وOCRA كمرجع؛ جدول الأمراض المهنية — التأمينات (النفق الرسغي والتهاب الأوتار)؛ لائحة الاشتراطات الصحية للمطاعم |
| الفائدة من التوثيق | إصابة المعصم لعامل المطبخ لا تصل للمعهد لأنه مقاول؛ التوثيق يضع معدات التقطيع والتناوب والسكاكين الحادة شرطاً في العقد ويُلزم بالإبلاغ |
| قناة الاتصال | مركز السلامة (المناوب) — مشرف المطعم بحسب العقد |

### الطبقة الاستباقية — قبل الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب | **معدات ومواد:** لا قطّاعات آلية للكميات الكبيرة، سكاكين كليلة، طاولات بارتفاع واحد، أدوات بمقابض ضيقة. **تنظيمية:** عامل واحد للتقطيع طوال الوردية، لا تناوب، عقد بلا شرط. **تدريب وكفاءة:** لا تدريب على تقنية التقطيع والمعصم المستقيم. **سلوكية:** ثني المعصم، قبضة قوية، سرعة زائدة في الذروة. **بيئية:** برد غرف التحضير يزيد التيبس |
| العواقب والأضرار | الموظفون — ١ طفيف · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٣ متوسط** (عمال المطبخ) · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ١ طفيف · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ٢ بسيط · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٢ بسيط |
| الإجراء الوقائي | (١) معدات تقلل التكرار **(بحسب ISO 11228-3)**: قطّاعات وخلاطات آلية للكميات الكبيرة (بواقياتها ME-05-02)، غسالة صحون، سكاكين حادة تُشحذ دورياً بمقابض مريحة، أدوات بمقابض عريضة، وطاولات بارتفاعات مختلفة أو قابلة للضبط ومنصات للقصار. (٢) تنظيم: تناوب المهام في الوردية (تقطيع، طهي، تقديم، غسيل) وحد للتقطيع المستمر بحسب المعيار، واستراحات قصيرة. (٣) تدريب العمال: المعصم مستقيم، القبضة الخفيفة، تقنية التقطيع، الإطالة. (٤) شرط المعدات والتناوب والتدريب والإبلاغ عن الإصابات في عقد التشغيل. (٥) الفحص الطبي الدوري لعمال المطبخ يشمل المعصم (الطبيب أو طبيب المشغّل). (٦) بند «القطّاعات والسكاكين والتناوب» في تفتيش المطعم |
| الإجراء التصحيحي | عند تقطيع يدوي لكميات كبيرة: قطّاعة. عند سكاكين كليلة: شحذ. عند عامل واحد للتقطيع: تناوب. عند شكاوى معصم متكررة: مراجعة المهمة وإنذار المشغّل |
| التقييم بعد الإجراءات | المعدات والتناوب والتدريب تخفض الاحتمالية من ٤ إلى ٢؛ الخطورة تبقى ٣. الدرجة المتبقية ≈ ٦ (منخفض) |
| الجهة والشخص | مدير المشغّل ومشرف المطعم بحسب العقد (المعدات والتناوب والتدريب) · ٢٠ مسؤول السلامة بالمعهد (الشرط والتفتيش) · ٢ مدير المرافق والصيانة (الطاولات ومعدات المعهد) · ٤ طبيب المعهد (الفحص والشكاوى) |

### الطبقة التشغيلية — أثناء العمل الطبيعي

| الخلية | المحتوى |
|---|---|
| الأسباب | **سلوكية:** عامل يقطع بمعصم مثني بسرعة في الذروة، يستخدم سكيناً كليلاً بقوة. **تنظيمية:** غياب زميل يلغي التناوب، فعالية تضاعف الكمية. **معدات ومواد:** القطّاعة معطلة فيعودون لليدوي. **اتصال وإشراف:** الألم يُكتم |
| العواقب والأضرار | الموظفون — ١ طفيف · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٣ متوسط** · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ١ طفيف · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ٢ بسيط · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٢ بسيط |
| الإجراء الوقائي (الضوابط القائمة) | (١) التناوب في كل وردية بجدول، والقطّاعة للكميات. (٢) شحذ السكاكين بجدول. (٣) المشرف يراقب المعصم والسرعة. (٤) الإطالة في الاستراحات. (٥) الألم أو التنميل = بلاغ للمشرف والطبيب |
| الإجراء التصحيحي | عند غياب التناوب: ترتيب. عند قطّاعة معطلة: إصلاح عاجل. عند شكوى: إحالة وتخفيف |
| التقييم بعد الإجراءات | التناوب والمعدات تُبقي الاحتمالية عند ٢؛ الخطورة تبقى ٣. الدرجة ≈ ٦ (منخفض) |
| الجهة والشخص | مشرف الوردية في المطعم (التناوب والمراقبة) · ٨ المنسق في المكان (التفتيش) · ٤ طبيب المعهد (الشكاوى) |

### طبقة الاستجابة — عند وقوع الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب (ما يفاقم الحدث) | **تدريب وكفاءة:** الاستمرار بمعصم متنمل. **تنظيمية:** المشغّل لا يحيل ولا يبلغ. **اتصال وإشراف:** العامل يخشى فقدان العمل |
| العواقب والأضرار | الموظفون — ١ طفيف · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٣ متوسط** (المصاب) · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ١ طفيف · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ٢ بسيط · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٢ بسيط |
| الإجراء الوقائي (تسلسل الاستجابة) | (١) **اكتشاف:** ألم أو تنميل مستمر في المعصم أو الأصابع أو المرفق، أو ضعف القبضة. (٢) **تدخل أولي:** التوقف عن المهمة المتكررة، الراحة، كمادة باردة. (٣) **إحالة:** الطبيب للتقييم (نفق رسغي، التهاب أوتار) وجبيرة وعلاج، وإبلاغ المعهد. (٤) **تصعيد:** ضعف عضلي أو تنميل ليلي مستمر ← التخصص. (٥) **استعادة:** عودة لمهمة غير متكررة بتوصية الطبيب، تسجيل كإصابة عمل لدى المشغّل وسجل المعهد |
| الإجراء التصحيحي | تحقيق: المهمة والمعدات والتناوب ← تصحيح وإنذار تعاقدي ← تسجيل ← تعميم |
| التقييم بعد الإجراءات | التوقف والإحالة يمنعان الجراحة غالباً فتنخفض الخطورة الفعلية من ٣ إلى ٢؛ الاحتمالية لا تتأثر. **الدرجة المتبقية للكتاب ≈ ٤ (منخفض) بعد الطبقات الثلاث** |
| الجهة والشخص | ٤ طبيب المعهد (التقييم) · مشرف الوردية (الإيقاف والإبلاغ) · ٢٠ مسؤول السلامة بالمعهد (التحقيق) |

**خلايا فارغة:** لا شيء. **الأرقام:** ٣×٤=١٢. أعلى أثر بين الفئات ٣ = الخطورة ٣.

## ER-04-02 — الحركات المتكررة والقوة اليدوية في أعمال التنظيف (مسح، عصر، فرك)
**الحالة:** **معتمد** (تفويض المستخدم ٢٠٢٦-٠٩-١١ — قرار ٣٢)

### الرأس

| الخلية | المحتوى |
|---|---|
| الكود | ER-04-02 |
| الصنف / الفرع | ٧ الإرجونومية / ٧-٤ الحركات المتكررة والقوة اليدوية |
| العنوان | الحركات المتكررة والقوة اليدوية في أعمال التنظيف (مسح، عصر، فرك) |
| الوصف | **المصدر:** مسح مساحات واسعة بحركات ذراع متكررة، عصر الممسحة والخرق باليد، فرك الأحواض والمراحيض والزجاج بقوة، تلميع الأرضيات بآلات تهتز (الاهتزاز في الصنف ١)، وحمل دلاء الماء، لساعات يومياً بأدوات ثقيلة ومقابض ضيقة ومواد تنظيف تجفف الجلد. **التعرض:** عمال النظافة (أكبر فئة عمال في المعهد). **الحدث المحتمل:** النفق الرسغي، التهاب أوتار المعصم والمرفق والكتف، وإصابات الكتف من الحركة الجانبية المتكررة. **الموقع:** كل الأماكن. |
| الخطورة | **٣ — متوسط** (مقترح): إصابات معصم وكتف مزمنة |
| الاحتمالية | **٤ — مرجح** (مقترح): التكرار والقوة جوهر العمل ولا أدوات ميسِّرة |
| الدرجة | **١٢ — عالٍ** |
| المرجع القانوني | نظام العمل م١٢٢؛ ISO 11228-3 وOCRA كمرجع؛ جدول الأمراض المهنية — التأمينات؛ لائحة مسؤول السلامة |
| الفائدة من التوثيق | عصّارة بدواسة وممسحة ميكروفايبر خفيفة تزيلان آلاف العصرات؛ التوثيق يضع الأدوات الميسِّرة والتناوب في عقد النظافة الذي يُقاس بالمساحة فقط |
| قناة الاتصال | مركز السلامة (المناوب) — مشرف النظافة بحسب العقد ومدير المرافق |

### الطبقة الاستباقية — قبل الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب | **معدات ومواد:** ممسحات قطنية ثقيلة تحتاج عصراً يدوياً، دلاء بلا عصّارة، فرش صغيرة تحتاج قوة، لا آلات فرك للمساحات الكبيرة، مقابض ضيقة، مواد تنظيف قوية بلا قفازات مناسبة. **تنظيمية:** مساحة كبيرة لكل عامل، لا تناوب بين المهام، عقد بالمساحة. **تدريب وكفاءة:** لا تدريب على التقنية. **سلوكية:** فرك بقوة زائدة، عصر بالتواء المعصم. **بيئية:** حر يزيد الإجهاد |
| العواقب والأضرار | الموظفون — ١ طفيف · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٣ متوسط** (النظافة) · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ١ طفيف · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ٢ بسيط · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٢ بسيط |
| الإجراء الوقائي | (١) أدوات ميسِّرة **(بحسب ISO 11228-3)**: ممسحات ميكروفايبر خفيفة مسطحة بمقابض قابلة للضبط، عصّارات بدواسة أو رافعة، عربات نظافة متكاملة، آلات فرك وتلميع للمساحات الكبيرة، فرش بمقابض عريضة ويد طويلة، بخاخات بدل الفرك، ومواد تنظيف تقلل الفرك. (٢) تنظيم: تناوب المهام في الوردية (مسح، تلميع، جمع، دورات مياه)، مساحة معقولة لكل عامل، واستراحات. (٣) تدريب: المعصم المستقيم، القبضة الخفيفة، الجسم كله في المسح لا الذراع، الإطالة. (٤) شرط الأدوات والتناوب والتدريب والإبلاغ في عقد النظافة (يُقاس بالجودة لا بالمساحة فقط). (٥) الفحص الطبي الدوري لعمال النظافة. (٦) بند «الأدوات الميسِّرة والعربات والتناوب» في تفتيش النظافة |
| الإجراء التصحيحي | عند ممسحات قطنية ثقيلة وعصر يدوي: استبدال وشرط العقد. عند مساحة مفرطة: إعادة توزيع. عند شكاوى متكررة: مراجعة وإنذار المقاول |
| التقييم بعد الإجراءات | الأدوات والتناوب والتدريب تخفض الاحتمالية من ٤ إلى ٢؛ الخطورة تبقى ٣. الدرجة المتبقية ≈ ٦ (منخفض) |
| الجهة والشخص | ٢ مدير المرافق والصيانة (العقد والأدوات) · مدير مقاول النظافة ومشرفه (التطبيق والتناوب — دور نظامي خارج البطاقات) · ٢٠ مسؤول السلامة بالمعهد (الشرط والتفتيش والتدريب) · ٤ طبيب المعهد (الفحص) |

### الطبقة التشغيلية — أثناء العمل الطبيعي
