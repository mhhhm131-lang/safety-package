# جداول الفرع ١-٤ — الاهتزاز

---

## PH-04-01 — اهتزاز اليد والذراع من الأدوات الكهربائية اليدوية في أعمال الصيانة (مثاقب، جلاخات)
**الحالة:** **معتمد** (تفويض المستخدم ٢٠٢٦-٠٩-١١ — قرار ٣٢)

### الرأس

| الخلية | المحتوى |
|---|---|
| الكود | PH-04-01 |
| الصنف / الفرع | ١ الفيزيائية — عوامل البيئة / ١-٤ الاهتزاز |
| العنوان | اهتزاز اليد والذراع من الأدوات الكهربائية اليدوية في أعمال الصيانة (مثاقب، جلاخات) |
| الوصف | **المصدر:** أدوات يدوية مهتزة: مثاقب دقّاقة، جلاخات زاوية، مناشير، مفكات صدمية، آلات صنفرة، أثناء الصيانة والتركيب والتعديلات. **التعرض:** فنيو المرافق والكهرباء والنجارة وعمال المقاولين الذين يمسكون الأداة لفترات متكررة، ويزيد التعرض في البرد وبقبضة شديدة وأدوات متهالكة. **الحدث المحتمل:** متلازمة اهتزاز اليد والذراع: تنميل وخدر، ابيضاض الأصابع، ضعف القبضة، وتلف أعصاب وأوعية دائم بالتراكم عبر السنوات؛ ضرر بطيء لا يُربط بسببه غالباً. **الموقع:** ورش الصيانة والغرف الفنية وأي موقع أعمال في المبنى. |
| الخطورة | **٣ — متوسط** (مقترح): تلف عصبي وعائي دائم يمس القدرة على العمل، لكنه لا يهدد الحياة |
| الاحتمالية | **٢ — غير مرجح** (مقترح): الاستخدام في المعهد متقطع لا يومياً كورش الصناعة؛ يرتفع لدى فني بعينه يتولى كل أعمال الثقب |
| الدرجة | **٦ — منخفض** |
| المرجع القانوني | نظام العمل م١٢٢؛ ISO 5349 (قياس وتقييم اهتزاز اليد والذراع)؛ التوجيه الأوروبي 2002/44/EC كمرجع لحدود التعرض اليومي (قيمة الفعل ٢٫٥ م/ث² والحد ٥ م/ث²)؛ جدول الأمراض المهنية — التأمينات (أمراض الاهتزاز) |
| الفائدة من التوثيق | ضرر يظهر بعد سنوات ولا يُنسب لسببه؛ التوثيق يفرض اختيار أدوات منخفضة الاهتزاز وتوزيع الأعمال وتسجيل زمن الاستخدام، فيصير المرض المهني قابلاً للإثبات والمنع |
| قناة الاتصال | مركز السلامة (المناوب) — مدير المرافق والصيانة |

### الطبقة الاستباقية — قبل الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب | **معدات ومواد:** أدوات قديمة أو رخيصة عالية الاهتزاز، لقم ومحامل تالفة تضاعف الاهتزاز، لا قفازات مضادة. **تنظيمية:** فني واحد يتولى كل أعمال الثقب والجلخ، ولا حد لزمن الاستخدام اليومي. **تدريب وكفاءة:** القبضة الشديدة والضغط الزائد على الأداة. **بيئية:** العمل في غرف باردة يزيد الأثر الوعائي |
| العواقب والأضرار | الموظفون — **٣ متوسط** (فنيو الصيانة) · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٣ متوسط** (أعمال التركيب والتعديل) · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ٢ بسيط (أمراض الدورة الدموية) · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ١ طفيف · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٣ متوسط (تعويض مرض مهني، مسؤولية عن عامل المقاول) |
| الإجراء الوقائي | (١) الشراء بمعيار: أدوات منخفضة الاهتزاز بقيمة انبعاث مُعلنة من المصنّع، ومقابض مضادة للاهتزاز. (٢) حساب زمن الاستخدام اليومي المسموح لكل أداة من قيمة انبعاثها **(بحسب ISO 5349 وقيمة الفعل ٢٫٥ م/ث²)** ولصقه على الأداة أو في سجل الورشة. (٣) توزيع أعمال الثقب والجلخ على أكثر من فني وتناوبها. (٤) قفازات مضادة للاهتزاز ومناسبة للمقاس. (٥) صيانة الأدوات: استبدال اللقم والأقراص والمحامل التالفة. (٦) تدريب على القبضة الخفيفة وترك الأداة تعمل بوزنها وأخذ فترات راحة. (٧) شرط الأدوات والتناوب في عقود المقاولين |
| الإجراء التصحيحي | عند رصد أداة بلا قيمة انبعاث أو تالفة في الجولة: إخراجها من الخدمة حتى الاستبدال أو الإصلاح. عند فني يتجاوز زمن الاستخدام المحسوب: إعادة توزيع الأعمال |
| التقييم بعد الإجراءات | الأدوات المنخفضة الاهتزاز وحد الزمن والتناوب تخفض الاحتمالية من ٢ إلى ١؛ الخطورة تبقى ٣. الدرجة المتبقية ≈ ٣ (منخفض) |
| الجهة والشخص | ٢ مدير المرافق والصيانة (معيار الشراء والتوزيع والصيانة) · ٢٠ مسؤول السلامة بالمعهد (حساب الزمن والتدريب وشرط العقود) |

### الطبقة التشغيلية — أثناء العمل الطبيعي

| الخلية | المحتوى |
|---|---|
| الأسباب | **سلوكية:** استمرار الثقب ساعات متصلة لإنهاء العمل، عدم لبس القفازات، الضغط الشديد على الأداة. **صيانة وتشغيل:** لقمة كليلة تُطيل الزمن وتزيد الاهتزاز، أداة مهتزة أكثر من المعتاد لم تُبلَّغ. **بيئية:** عمل في غرفة باردة. **اتصال وإشراف:** لا سجل لزمن استخدام الأدوات |
| العواقب والأضرار | الموظفون — **٣ متوسط** (الفنيون) · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٣ متوسط** · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ٢ بسيط · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ١ طفيف · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٣ متوسط (تعويض مرض مهني) |
| الإجراء الوقائي (الضوابط القائمة) | (١) تسجيل زمن استخدام الأدوات المهتزة في بطاقة العمل اليومية والالتزام بالحد المحسوب. (٢) قفازات مضادة للاهتزاز والحفاظ على دفء اليدين. (٣) فترات راحة قصيرة كل نصف ساعة من الاستخدام المتصل. (٤) استبدال اللقم والأقراص الكليلة فوراً. (٥) بند «الأدوات المهتزة: الحالة والزمن» في فحص الورشة الشهري. (٦) الإبلاغ عن أي أداة صار اهتزازها غير معتاد كعطل |
| الإجراء التصحيحي | عند تنميل أو ابيضاض أصابع بعد العمل: إيقاف الاستخدام وتسجيل شبه حادث وإحالة طبية ومراجعة الزمن والأداة. عند أداة زائدة الاهتزاز: إخراج من الخدمة |
| التقييم بعد الإجراءات | تسجيل الزمن والقفازات والراحة تُبقي الاحتمالية عند ١ وتكشف الأعراض مبكراً فتنخفض الخطورة الفعلية إلى ٢. الدرجة ≈ ٢ (منخفض) |
| الجهة والشخص | ٢ مدير المرافق والصيانة عبر مشرف الصيانة (الزمن والأدوات) · مشرف المقاول (عماله — دور نظامي خارج البطاقات) · ٨ المنسق في المكان (فحص الورشة) |

### طبقة الاستجابة — عند وقوع الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب (ما يفاقم الحدث) | **تنظيمية:** لا سجل زمن استخدام فيصعب الإثبات والتحقيق. **اتصال وإشراف:** الفني يخفي الأعراض خشية فقدان العمل. **تدريب وكفاءة:** الاستمرار في استخدام الأدوات بعد ظهور الأعراض |
| العواقب والأضرار | الموظفون — **٣ متوسط** (المصاب) · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٣ متوسط** (المصاب) · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ٢ بسيط · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ١ طفيف · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٣ متوسط (تعويض مرض مهني) |
| الإجراء الوقائي (تسلسل الاستجابة) | (١) **اكتشاف:** شكوى تنميل أو ابيضاض أصابع أو ضعف قبضة، أو فحص دوري. (٢) **إنذار:** إبلاغ مسؤول السلامة والطبيب. (٣) **تدخل أولي:** إيقاف كل عمل بأدوات مهتزة للفني فوراً وإحالته للطبيب. (٤) **تصعيد:** تأكيد متلازمة الاهتزاز ← تسجيلها مرضاً مهنياً وإبلاغ التأمينات. (٥) **احتواء:** مراجعة أدوات الورشة وزمن استخدام كل فني. (٦) **استعادة:** إعادة الفني لأعمال بلا اهتزاز بحسب رأي الطبيب |
| الإجراء التصحيحي | تحقيق: أي أداة وكم ساعة وبأي قفازات؟ ← استبدال الأدوات المسببة وتشديد حد الزمن ← فحص بقية الفنيين الذين يستخدمون الأدوات نفسها |
| التقييم بعد الإجراءات | الإيقاف المبكر يمنع التلف الدائم فتنخفض الخطورة الفعلية من ٣ إلى ٢؛ الاحتمالية لا تتأثر. **الدرجة المتبقية للكتاب ≈ ٢ (منخفض) بعد الطبقات الثلاث** |
| الجهة والشخص | ٢٠ مسؤول السلامة بالمعهد (الإحالة والتسجيل والتحقيق) · ٤ طبيب المعهد (التشخيص والرأي) · ٢ مدير المرافق والصيانة (الأدوات والتوزيع) |

**خلايا فارغة:** لا شيء. **الأرقام:** ٣×٢=٦. أعلى أثر بين الفئات ٣ = الخطورة ٣.

## PH-04-02 — اهتزاز الجسم الكلي من قيادة المركبات والمعدات المتحركة (حافلات، رافعات شوكية في المخازن)
**الحالة:** **معتمد** (تفويض المستخدم ٢٠٢٦-٠٩-١١ — قرار ٣٢)

### الرأس

| الخلية | المحتوى |
|---|---|
| الكود | PH-04-02 |
| الصنف / الفرع | ١ الفيزيائية — عوامل البيئة / ١-٤ الاهتزاز |
| العنوان | اهتزاز الجسم الكلي من قيادة المركبات والمعدات المتحركة (حافلات، رافعات شوكية في المخازن) |
| الوصف | **المصدر:** اهتزاز ينتقل عبر المقعد إلى الجسم كله: الرافعات الشوكية والعربات الكهربائية في المخازن على أرضيات غير مستوية، وحافلات نقل المتدربين والمركبات الخدمية على الطرق، وآلات تنظيف الأرضيات الراكبة. **التعرض:** سائقو الرافعات وعمال المخازن، سائقو الحافلات والمركبات الخدمية، عمال النظافة على الآلات الراكبة؛ التعرض يومي ولساعات لبعضهم. **الحدث المحتمل:** آلام أسفل الظهر واضطرابات القرص الفقري بالتراكم، وإجهاد ونعاس يزيد خطر الحوادث؛ ضرر بطيء يُنسب للعمر لا للعمل. **الموقع:** المخازن (HZ-08)، مواقف الحافلات في القبو (HZ-01)، الطرق الخارجية. |
| الخطورة | **٣ — متوسط** (مقترح): اضطرابات ظهر مزمنة تسبب غياباً وعجزاً جزئياً؛ لا تهدد الحياة مباشرة |
| الاحتمالية | **٢ — غير مرجح** (مقترح): عدد السائقين ومشغلي الرافعات قليل، والمسافات داخل المخازن قصيرة؛ يرتفع لسائقي الحافلات بدوام كامل |
| الدرجة | **٦ — منخفض** |
| المرجع القانوني | نظام العمل م١٢٢؛ ISO 2631 (تقييم اهتزاز الجسم الكلي)؛ التوجيه الأوروبي 2002/44/EC كمرجع للحدود (قيمة الفعل ٠٫٥ م/ث² والحد ١٫١٥)؛ اشتراطات الهيئة العامة للنقل لحافلات نقل الركاب |
| الفائدة من التوثيق | يربط آلام الظهر لدى السائقين ومشغلي الرافعات بسببها الحقيقي، ويحدد ضوابط رخيصة: مقعد معلّق وأرضية مستوية وحد زمن؛ ويغطي المقاولين الذين يشغّلون الحافلات والمخازن |
| قناة الاتصال | مركز السلامة (المناوب) — مدير الخدمات أو مدير المخازن بحسب العقد |

### الطبقة الاستباقية — قبل الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب | **معدات ومواد:** رافعات وحافلات بمقاعد بلا تعليق أو بتعليق تالف، إطارات صلبة. **فنية/هندسية:** أرضيات مخازن متشققة وعتبات ومنحدرات حادة. **تنظيمية:** لا حد لزمن القيادة المتصل ولا تناوب بين سائقي الرافعات. **تدريب وكفاءة:** قيادة سريعة على العوائق وضبط خاطئ للمقعد. **صيانة وتشغيل:** صيانة التعليق والإطارات مهملة |
| العواقب والأضرار | الموظفون — **٣ متوسط** (سائقو المركبات الخدمية وعمال المخازن) · المتدربون والزوار — ١ طفيف (ركاب الحافلات لفترات قصيرة) · المقاولون وعمالهم — **٣ متوسط** (سائقو الحافلات ومشغلو الرافعات بالعقد) · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ٢ بسيط (مشكلات ظهر سابقة) · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ١ طفيف · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٣ متوسط (تعويض مرض مهني، مسؤولية عن عامل المقاول) |
| الإجراء الوقائي | (١) معيار للمعدات: مقاعد معلّقة قابلة للضبط في الرافعات وآلات التنظيف الراكبة، وحافلات بتعليق سليم في العقود. (٢) إصلاح أرضيات المخازن ومنحدراتها وإزالة العتبات الحادة. (٣) حد لزمن التشغيل المتصل للرافعات وتناوب المشغلين **(بحسب ISO 2631 وقيمة الفعل)**. (٤) تدريب المشغلين على ضبط المقعد والسرعة على العوائق. (٥) صيانة التعليق والإطارات في جدول المعدات. (٦) شرط المعدات والتناوب وفحص السائقين في عقود النقل والمخازن |
| الإجراء التصحيحي | عند رافعة بمقعد تالف أو أرضية متشققة في الجولة: بلاغ فحص بمهلة ومنع الاستخدام الطويل حتى الإصلاح. عند مقاول بحافلات بلا تعليق سليم: إنذار تعاقدي |
| التقييم بعد الإجراءات | المقاعد المعلّقة والأرضيات وحد الزمن تخفض الاحتمالية من ٢ إلى ١؛ الخطورة تبقى ٣. الدرجة المتبقية ≈ ٣ (منخفض) |
| الجهة والشخص | مدير المخازن ومدير الخدمات بحسب العقد (المعدات والتناوب) · ٢ مدير المرافق والصيانة (الأرضيات وصيانة المعدات) · ٢٠ مسؤول السلامة بالمعهد (المعيار وشرط العقود) |

### الطبقة التشغيلية — أثناء العمل الطبيعي

| الخلية | المحتوى |
|---|---|
| الأسباب | **سلوكية:** القيادة السريعة على العوائق، مقعد غير مضبوط، ساعات متصلة بلا نزول. **صيانة وتشغيل:** تعليق تالف لم يُبلَّغ، إطار مفرّغ. **بيئية:** أرضية تالفة مؤقتاً بسبب أعمال. **اتصال وإشراف:** لا سجل لساعات التشغيل |
| العواقب والأضرار | الموظفون — **٣ متوسط** · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٣ متوسط** · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ٢ بسيط · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ١ طفيف · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٣ متوسط (تعويض مرض مهني) |
| الإجراء الوقائي (الضوابط القائمة) | (١) ضبط المقعد قبل كل وردية وفحص التعليق والإطارات ضمن فحص المعدة اليومي. (٢) السرعة المنخفضة على العوائق والمنحدرات. (٣) نزول وتمدد كل ساعة قيادة متصلة، والتناوب بين المشغلين. (٤) تسجيل ساعات التشغيل في سجل المعدة. (٥) الإبلاغ عن أي أرضية تالفة كبلاغ فحص. (٦) بند «مقاعد الرافعات والأرضيات» في نموذج فحص المخازن |
| الإجراء التصحيحي | عند ألم ظهر متكرر لمشغل: إحالة طبية وتقليل الزمن وتسجيل شبه حادث. عند تعليق أو إطار تالف: إيقاف المعدة حتى الإصلاح. عند أرضية تالفة: تحويل المسار حتى الإصلاح |
| التقييم بعد الإجراءات | الفحص اليومي والتناوب والسرعة تُبقي الاحتمالية عند ١ وتكشف الأعراض مبكراً فتنخفض الخطورة الفعلية إلى ٢. الدرجة ≈ ٢ (منخفض) |

### طبقة الاستجابة — عند وقوع الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب (ما يفاقم الحدث) | **تنظيمية:** لا سجل ساعات ولا فحص طبي سابق فيصعب إثبات المرض المهني. **اتصال وإشراف:** المشغل يواصل بعد الألم خشية فقد العمل. **تدريب وكفاءة:** الاستهانة بألم الظهر كأمر معتاد |
| العواقب والأضرار | الموظفون — **٣ متوسط** (المصاب) · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٣ متوسط** (المصاب) · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ٢ بسيط · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ١ طفيف · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٣ متوسط (تعويض مرض مهني) |
| الإجراء الوقائي (تسلسل الاستجابة) | (١) **اكتشاف:** شكوى ألم ظهر مستمر مرتبط بالقيادة أو فحص دوري. (٢) **إنذار:** إبلاغ مسؤول السلامة والطبيب. (٣) **تدخل أولي:** إيقاف القيادة والتشغيل وإحالة طبية. (٤) **تصعيد:** تأكيد اضطراب مرتبط بالاهتزاز ← تسجيله مرضاً مهنياً وإبلاغ التأمينات. (٥) **احتواء:** فحص المعدة والمسار وساعات بقية المشغلين. (٦) **استعادة:** عودة المشغل لمهام بلا اهتزاز أو بزمن محدود بحسب الطبيب |
| الإجراء التصحيحي | تحقيق: المعدة والمقعد والمسار والساعات ← إصلاح أو استبدال وتشديد التناوب ← فحص بقية المشغلين ← إنذار تعاقدي للمقاول إن كانت معداته السبب |
| التقييم بعد الإجراءات | الإيقاف المبكر يمنع التدهور الدائم فتنخفض الخطورة الفعلية من ٣ إلى ٢؛ الاحتمالية لا تتأثر. **الدرجة المتبقية للكتاب ≈ ٢ (منخفض) بعد الطبقات الثلاث** |
| الجهة والشخص | ٢٠ مسؤول السلامة بالمعهد (الإحالة والتسجيل والتحقيق) · ٤ طبيب المعهد (التشخيص) · مدير المخازن أو مدير الخدمات (المعدة والمسار) |

**خلايا فارغة:** لا شيء. **الأرقام:** ٣×٢=٦. أعلى أثر بين الفئات ٣ = الخطورة ٣.
