# جداول الفرع ٧-٣ — الوضعيات الثابتة والمجهدة

## ER-03-01 — الوقوف الطويل الثابت للأمن والاستقبال وعمال المطاعم والمعارض
**الحالة:** **معتمد** (تفويض المستخدم ٢٠٢٦-٠٩-١١ — قرار ٣٢)

### الرأس

| الخلية | المحتوى |
|---|---|
| الكود | ER-03-01 |
| الصنف / الفرع | ٧ الإرجونومية / ٧-٣ الوضعيات الثابتة والمجهدة |
| العنوان | الوقوف الطويل الثابت للأمن والاستقبال وعمال المطاعم والمعارض |
| الوصف | **المصدر:** وظائف تفرض الوقوف ساعات متواصلة في مكان واحد: حراس البوابات والمداخل، موظفو الاستقبال خلف كاونتر عالٍ بلا مقعد، عمال خطوط التقديم والغسيل في المطاعم، والمنظمون في المعارض والفعاليات، على أرضيات صلبة وبأحذية غير مناسبة وفي حر خارجي أحياناً. **التعرض:** الأمن والاستقبال وعمال المطاعم ومنظمو الفعاليات وعمال النظافة في المداخل. **الحدث المحتمل:** آلام القدمين والساقين والظهر السفلي، دوالي الساقين، تورم، وإعياء يقلل اليقظة (مهم للأمن)، وتراكم على سنوات. **الموقع:** البوابات والمداخل والاستقبال (HZ-01)، المطاعم (HZ-05)، صالات الفعاليات (HZ-07). |
| الخطورة | **٢ — بسيط** (مقترح): آلام ودوالي تُعالج؛ أثر على يقظة الأمن |
| الاحتمالية | **٤ — مرجح** (مقترح): وظائف كاملة قائمة على الوقوف بلا مقاعد ولا تناوب |
| الدرجة | **٨ — عالٍ** |
| المرجع القانوني | نظام العمل م١٠١ (الراحة) وم١٢٢؛ ISO 11226 (تقييم الوضعيات الثابتة) كمرجع؛ جدول الأمراض المهنية — التأمينات (الدوالي في المهن الواقفة)؛ لائحة مسؤول السلامة |
| الفائدة من التوثيق | «الحارس يقف» بديهية لا تُناقش؛ التوثيق يعطيه مقعداً عالياً وحصيرة وتناوباً، وهي ما توصي به المعايير ويرفضه العرف |
| قناة الاتصال | مركز السلامة (المناوب) — رئيس قسم الأمن والسلامة ومشرف المطعم |

### الطبقة الاستباقية — قبل الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب | **تنظيمية:** لا مقاعد في نقاط الحراسة والاستقبال (يُعدّ الجلوس تقصيراً)، نوبات طويلة بلا تناوب أو استراحة، لا أحذية عمل. **فنية/هندسية:** أرضيات صلبة (رخام، خرسانة)، كاونترات بلا مساحة للجلوس، كشك حراسة بلا مقعد أو تكييف. **معدات ومواد:** لا حصائر مضادة للإجهاد، أحذية صلبة. **بيئية:** حر الساحات، برد الشتاء. **سلوكية:** الوقوف بثبات كامل بلا تحريك |
| العواقب والأضرار | الموظفون — **٢ بسيط** (الاستقبال) · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٢ بسيط** (الأمن والمطاعم والنظافة) · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — **٢ بسيط** (الحوامل ومرضى الدوالي) · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ٢ بسيط (انخفاض يقظة الأمن) · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ١ طفيف |
| الإجراء الوقائي | (١) قاعدة الوقوف **(بحسب ISO 11226)**: كل نقطة وقوف ثابت تُزود بمقعد عالٍ (جلوس-وقوف) يسمح بالتناوب بين الوضعين دون الإخلال بالمهمة، وحصيرة مضادة للإجهاد على الأرضيات الصلبة، وتعميم أن الجلوس المتناوب مسموح ومطلوب. (٢) تناوب المواقع بين الواقف والمتحرك (حارس البوابة مع الجولة) كل فترة، واستراحات قصيرة منتظمة، ونوبات لا تتجاوز الحد النظامي. (٣) أحذية عمل مريحة بنعل ماص ضمن الزي (شرط في عقود الأمن والمطاعم والنظافة). (٤) أكشاك الحراسة بمقعد وتكييف وظل (PH-01). (٥) الفحص الدوري للعاملين الواقفين يشمل الساقين والدوالي (الطبيب). (٦) بند «المقاعد والحصائر والتناوب» في نماذج فحص HZ-01/HZ-05/HZ-07 |
| الإجراء التصحيحي | عند نقطة بلا مقعد أو حصيرة: توفير خلال المهلة. عند منع الجلوس من مشرف: توعية وتعميم. عند نوبة فوق الحد: تعديل الجدول. عند أحذية غير مناسبة: شرط العقد |
| التقييم بعد الإجراءات | المقاعد والحصائر والتناوب تخفض الاحتمالية من ٤ إلى ٢؛ الخطورة تبقى ٢. الدرجة المتبقية ≈ ٤ (منخفض) |
| الجهة والشخص | ٣ رئيس قسم الأمن والسلامة (المقاعد والتناوب والنوبات للأمن) · ٢ مدير المرافق والصيانة (الحصائر والأكشاك والعقود) · ٢٠ مسؤول السلامة بالمعهد (القاعدة والتعميم والنماذج) · مدير المشغّل بحسب العقد (المطاعم) · ٤ طبيب المعهد (الفحص) |

### الطبقة التشغيلية — أثناء العمل الطبيعي

| الخلية | المحتوى |
|---|---|
| الأسباب | **سلوكية:** حارس لا يجلس أمام المراجعين خجلاً، عامل مطعم يقف الوردية كاملة في الذروة. **تنظيمية:** فعالية طويلة بمنظمين واقفين بلا تناوب، نوبة إضافية لغياب زميل. **بيئية:** حر الساحة، أرضية رخام. **اتصال وإشراف:** الألم يُكتم |
| العواقب والأضرار | الموظفون — **٢ بسيط** · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٢ بسيط** · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — **٢ بسيط** · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ٢ بسيط · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ١ طفيف |
| الإجراء الوقائي (الضوابط القائمة) | (١) التناوب جلوس-وقوف والاستراحات بجدول النوبة، والمشرف يشجع لا يمنع. (٢) الفعاليات الطويلة بتناوب المنظمين (بند تجهيز القاعة). (٣) الحصيرة والمقعد في مكانهما (الفحص الشهري). (٤) تحريك القدمين والساقين أثناء الوقوف (تذكير في التدريب). (٥) ألم أو تورم متكرر = بلاغ وطبيب |
| الإجراء التصحيحي | عند حصيرة أو مقعد مفقود: إعادة. عند نوبة طويلة بلا تناوب: تعديل. عند شكوى: طبيب وتخفيف |
| التقييم بعد الإجراءات | التناوب والمعدات تُبقي الاحتمالية عند ٢؛ الخطورة تبقى ٢. الدرجة ≈ ٤ (منخفض) |
| الجهة والشخص | ٥ أفراد الأمن المكلفون (التناوب) · مشرف الوردية في المطعم (التناوب) · ٨ المنسق في المكان (الفعاليات والفحص) |

### طبقة الاستجابة — عند وقوع الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب (ما يفاقم الحدث) | **تدريب وكفاءة:** الاستمرار في الوقوف مع تورم أو ألم شديد. **تنظيمية:** لا بديل للحارس فيبقى. **بيئية:** حر يضاعف التورم والإغماء (BI-06-02) |
| العواقب والأضرار | الموظفون — **٢ بسيط** (المصاب) · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٢ بسيط** · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — **٢ بسيط** · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ٢ بسيط · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ١ طفيف |
| الإجراء الوقائي (تسلسل الاستجابة) | (١) **اكتشاف:** ألم شديد أو تورم أو دوار من الوقوف الطويل. (٢) **تدخل أولي:** الجلوس ورفع الساقين، ماء، ظل؛ بديل للنقطة (المركز يرتب). (٣) **إحالة:** الطبيب للتقييم (دوالي، تورم مستمر). (٤) **تصعيد:** إغماء ← مسار BI-06-02؛ ألم وتورم ساق واحدة مفاجئ ← جلطة محتملة، الطبيب فوراً. (٥) **استعادة:** تعديل النوبة أو المهمة بتوصية الطبيب، تسجيل |
| الإجراء التصحيحي | مراجعة: النوبة والتناوب والمعدات ← تعديل ← تسجيل ← تعميم |
| التقييم بعد الإجراءات | الجلوس والبديل والإحالة تُبقي الخطورة ٢؛ الاحتمالية لا تتأثر. **الدرجة المتبقية للكتاب ≈ ٤ (منخفض) بعد الطبقات الثلاث** |
| الجهة والشخص | ٩ المسعف في المكان (الإسعاف) · ٢١ مناوب مركز السلامة (البديل) · ٤ طبيب المعهد (التقييم) · ٣ رئيس قسم الأمن والسلامة (تعديل النوبة) |

**خلايا فارغة:** لا شيء. **الأرقام:** ٢×٤=٨. أعلى أثر بين الفئات ٢ = الخطورة ٢.

## ER-03-02 — الانحناء والالتواء المتكرر في التنظيف وترتيب الرفوف المنخفضة وأعمال الصيانة
**الحالة:** **معتمد** (تفويض المستخدم ٢٠٢٦-٠٩-١١ — قرار ٣٢)

### الرأس

| الخلية | المحتوى |
|---|---|
| الكود | ER-03-02 |
| الصنف / الفرع | ٧ الإرجونومية / ٧-٣ الوضعيات الثابتة والمجهدة |
| العنوان | الانحناء والالتواء المتكرر في التنظيف وترتيب الرفوف المنخفضة وأعمال الصيانة |
| الوصف | **المصدر:** مهام تفرض انحناء الجذع للأمام أو التواءه مئات المرات يومياً: مسح الأرضيات بممسحة قصيرة، تنظيف دورات المياه والأحواض المنخفضة، جمع النفايات من السلال، ترتيب الرفوف السفلى في المخازن والأرشيف، أعمال الصيانة على معدات منخفضة، وتفريغ غسالة الصحون. **التعرض:** عمال النظافة (الأكثر)، عمال المخازن والمطابخ، فنيو الصيانة. **الحدث المحتمل:** آلام الظهر السفلي المزمنة وانزلاق الأقراص من الانحناء المتكرر خاصة مع الالتواء والحمل. **الموقع:** كل الأماكن للنظافة، المخازن (HZ-08)، المطابخ (HZ-05)، الغرف الفنية (HZ-03). |
| الخطورة | **٣ — متوسط** (مقترح): انزلاق قرص يحتاج علاجاً طويلاً وقد يعجز |
| الاحتمالية | **٤ — مرجح** (مقترح): الانحناء المتكرر جوهر عمل النظافة ولا أدوات طويلة |
| الدرجة | **١٢ — عالٍ** |
| المرجع القانوني | نظام العمل م١٢٢؛ ISO 11226 وأدوات RULA/REBA (تقييم وضعية الجذع) كمرجع؛ جدول الأمراض المهنية — التأمينات؛ لائحة مسؤول السلامة |
| الفائدة من التوثيق | ممسحة أطول بعشرين سنتيمتراً تزيل آلاف الانحناءات سنوياً؛ التوثيق يضع الأدوات الطويلة وارتفاع الرفوف والدوران بالقدمين في عقد النظافة والتدريب |
| قناة الاتصال | مركز السلامة (المناوب) — مشرف النظافة بحسب العقد ومدير المرافق |

### الطبقة الاستباقية — قبل الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب | **معدات ومواد:** ممسحات ومكانس قصيرة، دلاء أرضية بلا عجلات، سلال بلا عجلات تحتاج انحناءً، أدوات تنظيف بلا يد طويلة للأماكن المنخفضة. **فنية/هندسية:** رفوف سفلى قرب الأرض للثقيل (ER-01-02)، أحواض منخفضة، معدات صيانة على الأرض. **تنظيمية:** لا تقييم للوضعيات، لا حصص عمل متنوعة، عقد النظافة يحدد المساحة لا الأدوات. **تدريب وكفاءة:** لا تدريب على الانحناء بالركبتين والدوران بالقدمين. **سلوكية:** الالتواء مع الانحناء، حمل وانحناء معاً |
| العواقب والأضرار | الموظفون — ٢ بسيط (المخازن) · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٣ متوسط** (النظافة والمطابخ والصيانة) · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ١ طفيف · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ٢ بسيط · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٢ بسيط |
| الإجراء الوقائي | (١) أدوات بمقابض طويلة قابلة للضبط **(بحسب ISO 11226 وتقييم REBA)**: ممسحات ومكانس وفراشي دورات المياه وجامعات النفايات بيد طويلة، دلاء وعربات نظافة بعجلات وعصّارة بدواسة، وسلال نفايات بارتفاع لا يحتاج انحناءً، ومعدات صيانة على طاولات أو حوامل. (٢) تصميم التخزين: الثقيل والمتكرر بين الركبة والكتف (ER-01-02، ER-05-02). (٣) تنويع المهام في الوردية (مسح، رفوف، تلميع واقفاً) لتقليل التكرار، واستراحات قصيرة. (٤) تدريب عمال النظافة والمخازن والصيانة: الانحناء بالركبتين مع ظهر مستقيم، الدوران بالقدمين لا الجذع، القرب من العمل. (٥) شرط الأدوات الطويلة والعربات والتدريب في عقد النظافة والتشغيل. (٦) بند «الأدوات والعربات والوضعيات» في تفتيش النظافة ونماذج الفحص |
| الإجراء التصحيحي | عند أدوات قصيرة: استبدال خلال المهلة وشرط العقد. عند دلاء بلا عجلات: استبدال. عند رفوف سفلى للثقيل: إعادة توزيع. عند عمال غير مدربين: تدريب |
| التقييم بعد الإجراءات | الأدوات الطويلة والتصميم والتدريب تخفض الاحتمالية من ٤ إلى ٢؛ الخطورة تبقى ٣. الدرجة المتبقية ≈ ٦ (منخفض) |
| الجهة والشخص | ٢ مدير المرافق والصيانة (الأدوات والعقود والرفوف) · ٢٠ مسؤول السلامة بالمعهد (التقييم والتدريب والنماذج) · مشرف النظافة والمطعم بحسب العقد (التنويع والتطبيق) |

### الطبقة التشغيلية — أثناء العمل الطبيعي

| الخلية | المحتوى |
|---|---|
| الأسباب | **سلوكية:** عامل يمسح منحنياً بممسحة قصيرة لأنها أسرع، يلتوي وهو منحنٍ لجمع السلال، يرتب الرف السفلي جالساً القرفصاء طويلاً. **معدات ومواد:** عصّارة الدلو تتعطل فيعصر باليد منحنياً. **تنظيمية:** مساحة كبيرة في وقت قصير. **اتصال وإشراف:** الألم يُكتم |
| العواقب والأضرار | الموظفون — ٢ بسيط · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٣ متوسط** · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ١ طفيف · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ٢ بسيط · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٢ بسيط |
| الإجراء الوقائي (الضوابط القائمة) | (١) الأدوات الطويلة والعربات تُستخدم فعلاً، والمشرف يراقب الوضعيات. (٢) التنويع في الوردية والاستراحات. (٣) الأدوات المعطلة تُستبدل لا تُعوَّض بالانحناء. (٤) تفتيش النظافة الأسبوعي: الأدوات والعربات. (٥) الألم = بلاغ وطبيب |
| الإجراء التصحيحي | عند وضعية سيئة ملاحظة: تذكير. عند أداة معطلة: استبدال. عند شكوى: إحالة وتعديل المهام |
| التقييم بعد الإجراءات | الاستخدام الفعلي والمراقبة تُبقي الاحتمالية عند ٢؛ الخطورة تبقى ٣. الدرجة ≈ ٦ (منخفض) |
| الجهة والشخص | مشرف النظافة (المراقبة والأدوات) · ٨ المنسق في المكان (التفتيش الأسبوعي) · ٤ طبيب المعهد (الشكاوى) |

### طبقة الاستجابة — عند وقوع الحدث

| الخلية | المحتوى |
