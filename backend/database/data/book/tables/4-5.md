# جداول الفرع ٤-٥ — الآلات والأجزاء المتحركة والأدوات

## ME-05-01 — الاحتكاك والانحشار بالأجزاء المتحركة لمعدات الغرف الفنية (مراوح، سيور، مضخات، محركات)
**الحالة:** **معتمد** (تفويض المستخدم ٢٠٢٦-٠٩-١١ — قرار ٣٢)

### الرأس

| الخلية | المحتوى |
|---|---|
| الكود | ME-05-01 |
| الصنف / الفرع | ٤ الميكانيكية والإنشائية / ٤-٥ الآلات والأجزاء المتحركة والأدوات |
| العنوان | الاحتكاك والانحشار بالأجزاء المتحركة لمعدات الغرف الفنية (مراوح، سيور، مضخات، محركات) |
| الوصف | **المصدر:** مراوح وحدات مناولة الهواء، سيور ومحاور المحركات، أعمدة المضخات، مراوح أبراج التبريد ومولدات الطوارئ، بحواجز مفقودة أو مفتوحة للصيانة، وتشغيل مفاجئ للمعدة أثناء العمل عليها (بلا عزل الطاقة). **التعرض:** فنيو التكييف والكهرباء والمولد والمضخات والمقاولون في الغرف الفنية. **الحدث المحتمل:** انحشار اليد أو الملابس أو الشعر في سير أو مروحة: بتر أصابع أو يد، جروح عميقة، سحب الجسم في المعدة. **الموقع:** الغرف الفنية وغرف التكييف والمضخات والمولد (HZ-03). |
| الخطورة | **٤ — كبير** (مقترح): بتر أصابع أو يد إصابة دائمة؛ السحب الكامل نادر |
| الاحتمالية | **٢ — غير مرجح** (مقترح): الغرف الفنية مغلقة والفنيون قلة، لكن الحواجز المفتوحة والعمل بلا عزل شائعان |
| الدرجة | **٨ — عالٍ** |
| المرجع القانوني | OSHA 1910.212 (حماية الآلات) و1910.147 (عزل الطاقة — القفل والتعليم) كمرجع؛ ISO 12100 (سلامة الآلات)؛ نظام العمل م١٢٢؛ لائحة مسؤول السلامة؛ تصريح العمل (الصيانة على معدات متحركة) |
| الفائدة من التوثيق | الغرفة الفنية مغلقة فلا يفتشها إلا فنيها؛ التوثيق يفرض الحواجز وعزل الطاقة قبل الصيانة، وهما الضابطان اللذان يمنعان البتر |
| قناة الاتصال | مركز السلامة (المناوب) — مدير المرافق والصيانة |

### الطبقة الاستباقية — قبل الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب | **معدات ومواد:** حواجز سيور ومراوح مفقودة أو مخلوعة بعد صيانة، أزرار طوارئ معطلة. **تنظيمية:** لا إجراء عزل طاقة (قفل وتعليم) ولا تصريح، عمل فردي. **تدريب وكفاءة:** الصيانة والمعدة تعمل «لتشخيص الصوت»، لا تدريب على الحواجز والعزل. **سلوكية:** ملابس فضفاضة وخواتم وشعر مكشوف، إدخال اليد لإزالة عائق. **صيانة وتشغيل:** تشغيل آلي أو من غرفة تحكم بعيدة أثناء العمل |
| العواقب والأضرار | الموظفون — **٤ كبير** (فنيو المعهد) · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٤ كبير** (الصيانة) · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ١ طفيف · الممتلكات والأنظمة — ٢ بسيط (تلف المعدة) · استمرارية الأعمال — ٢ بسيط (توقف التكييف) · السمعة — ٢ بسيط / محلي · الخسائر المالية والقانونية — ٣ متوسط (إصابة دائمة) |
| الإجراء الوقائي | (١) مسح كل المعدات المتحركة في الغرف الفنية: حواجز ثابتة على السيور والمراوح والمحاور **(بحسب OSHA 1910.212 وISO 12100)**، وأزرار إيقاف طوارئ تعمل، وإعادة الحاجز بعد كل صيانة شرطاً للتسليم. (٢) إجراء عزل الطاقة (قفل وتعليم) مكتوب **(بحسب OSHA 1910.147)**: فصل المصدر، قفل شخصي ولوحة باسم الفني، التحقق من عدم التشغيل قبل العمل، وأقفال لكل فني. (٣) تصريح عمل للصيانة على المعدات المتحركة يشمل العزل والحاجز والعمل باثنين. (٤) قاعدة: لا تشخيص واليد داخل المعدة، لا ملابس فضفاضة ولا خواتم، الشعر مغطى. (٥) تدريب الفنيين والمقاولين على العزل والحواجز. (٦) بند «الحواجز وأزرار الطوارئ والأقفال» في نموذج فحص HZ-03 |
| الإجراء التصحيحي | عند حاجز مفقود: إيقاف المعدة أو حاجز مؤقت وتركيب خلال المهلة القصيرة. عند صيانة بلا عزل: إيقاف ومساءلة. عند زر طوارئ معطل: إصلاح فوري |
| التقييم بعد الإجراءات | الحواجز والعزل والتصريح تخفض الاحتمالية من ٢ إلى ١؛ الخطورة تبقى ٤. الدرجة المتبقية ≈ ٤ (منخفض) |
| الجهة والشخص | ٢ مدير المرافق والصيانة (الحواجز والأقفال والعقود) · ٢٠ مسؤول السلامة بالمعهد (إجراء العزل والتصريح والتدريب) · ١٧ فني التكييف ونظام الدخان (المعدات) · ١٩ فني الكهرباء (الفصل والقفل) |

### الطبقة التشغيلية — أثناء العمل الطبيعي

| الخلية | المحتوى |
|---|---|
| الأسباب | **سلوكية:** فني يفتح الحاجز والمعدة تعمل، يدخل يده لإزالة عائق، يعمل بلا قفل «لدقيقة»، زميل يشغّل من اللوحة. **تنظيمية:** عمل فردي ليلاً، تصريح بلا تحقق. **معدات ومواد:** حاجز لم يُعد بعد الصيانة السابقة. **بيئية:** ضوضاء تمنع سماع التحذير |
| العواقب والأضرار | الموظفون — **٤ كبير** · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٤ كبير** · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ١ طفيف · الممتلكات والأنظمة — ٢ بسيط · استمرارية الأعمال — ٢ بسيط · السمعة — ٢ بسيط / محلي · الخسائر المالية والقانونية — ٣ متوسط |
| الإجراء الوقائي (الضوابط القائمة) | (١) قفل شخصي ولوحة قبل فتح أي حاجز أو العمل على معدة، والتحقق بمحاولة التشغيل. (٢) الحاجز يُعاد قبل التشغيل، ولا تشغيل من اللوحة قبل التأكد من خلو المعدة ونداء الفني. (٣) العمل باثنين على المعدات المتحركة، وتسجيل الدخول للغرفة الفنية لدى المركز. (٤) لا ملابس فضفاضة ولا خواتم. (٥) بند الفحص الشهري HZ-03: الحواجز والأزرار والأقفال. (٦) أي حاجز مفتوح على معدة تعمل = بلاغ فحص |
| الإجراء التصحيحي | عند عمل بلا قفل: إيقاف ومساءلة. عند حاجز مفتوح: إيقاف المعدة وإعادته. عند تشغيل مفاجئ بلا إصابة: تسجيل حدث وشيك وتحقيق |
| التقييم بعد الإجراءات | القفل والحاجز والاثنان تُبقي الاحتمالية عند ١؛ الخطورة تبقى ٤. الدرجة ≈ ٤ (منخفض) |
| الجهة والشخص | ١٧ فني التكييف ونظام الدخان (القفل والحواجز) · ١٩ فني الكهرباء (الفصل) · ١٥ فني المولد الاحتياطي (المولد) · ١٤ فني مضخة الحريق (المضخات) · ٢١ مناوب مركز السلامة (سجل الدخول) |

### طبقة الاستجابة — عند وقوع الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب (ما يفاقم الحدث) | **تدريب وكفاءة:** سحب اليد المنحشرة بالقوة أو تشغيل المعدة عكسياً، التردد في إيقاف الطوارئ. **اتصال وإشراف:** الفني وحده في غرفة مغلقة صاخبة. **تنظيمية:** لا يُعرف مكان زر الطوارئ أو الفصل الرئيسي |
| العواقب والأضرار | الموظفون — **٤ كبير** (المصاب) · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٤ كبير** · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ١ طفيف · الممتلكات والأنظمة — ٢ بسيط · استمرارية الأعمال — ٢ بسيط · السمعة — ٢ بسيط / محلي · الخسائر المالية والقانونية — ٣ متوسط |
| الإجراء الوقائي (تسلسل الاستجابة) | (١) **اكتشاف:** انحشار يد أو ملابس في معدة، صراخ من غرفة فنية، أو فني لا يرد. (٢) **تدخل أولي:** **إيقاف الطوارئ فوراً وفصل المصدر وقفله**، عدم سحب المصاب بالقوة، تحرير الجزء المنحشر بفك المعدة أو قطع الملابس، وقف النزيف بالضغط ورفع الطرف. (٣) **إنذار:** المركز فوراً ← **٩٩٧** (و**٩٩٨** إن تعذر التحرير) والمسعف والمنقذ ومدير المرافق. (٤) **إسعاف:** ضغط مباشر، ضمادة، رفع الطرف؛ البتر: الجزء المبتور في كيس نظيف داخل كيس ثلج بلا تلامس مباشر يُرسل مع المصاب؛ مراقبة الصدمة. (٥) **احتواء:** حفظ المعدة مفصولة للتحقيق، إبعاد الآخرين. (٦) **استعادة:** فحص المعدة والحواجز قبل التشغيل، تسجيل |
| الإجراء التصحيحي | تحقيق: الحاجز والعزل والتصريح والانفراد ← تصحيح ومساءلة ← تسجيل إصابة عمل ← تعميم على كل الفنيين |
| التقييم بعد الإجراءات | الإيقاف الفوري والتحرير الصحيح وحفظ الجزء المبتور يخفضان الخطورة الفعلية من ٤ إلى ٣؛ الاحتمالية لا تتأثر. **الدرجة المتبقية للكتاب ≈ ٣ (منخفض) بعد الطبقات الثلاث** |
| الجهة والشخص | ١٩ فني الكهرباء أو الفني الحاضر (الإيقاف والفصل) · ٩ المسعف في المكان (النزيف والبتر) · ١٠ المنقذ (التحرير) · ٢١ مناوب مركز السلامة (الإنذار و٩٩٧) · ٢ مدير المرافق والصيانة (المعدة) · ٢٠ مسؤول السلامة بالمعهد (التحقيق) |

**خلايا فارغة:** لا شيء. **الأرقام:** ٤×٢=٨. أعلى أثر بين الفئات ٤ = الخطورة ٤.

## ME-05-02 — الجروح والبتر من معدات المطبخ (قطّاعات، خلاطات، سكاكين، مفارم)
**الحالة:** **معتمد** (تفويض المستخدم ٢٠٢٦-٠٩-١١ — قرار ٣٢)

### الرأس

| الخلية | المحتوى |
|---|---|
| الكود | ME-05-02 |
| الصنف / الفرع | ٤ الميكانيكية والإنشائية / ٤-٥ الآلات والأجزاء المتحركة والأدوات |
| العنوان | الجروح والبتر من معدات المطبخ (قطّاعات، خلاطات، سكاكين، مفارم) |
| الوصف | **المصدر:** قطّاعات الخضار واللحوم الكهربائية، المفارم، الخلاطات الكبيرة، شرائح اللحم، والسكاكين الحادة في مطابخ المعهد، تُستخدم بلا واقيات أو أثناء التنظيف والمعدة موصولة، أو بدفع الطعام باليد، أو بسكاكين على أسطح مبللة. **التعرض:** عمال المطبخ (طهاة، مساعدون، عمال غسيل) يومياً. **الحدث المحتمل:** جروح عميقة في اليد وبتر أصابع في القطّاعات والمفارم، وقد ينزف العامل بشدة. **الموقع:** المطابخ (HZ-05). |
| الخطورة | **٣ — متوسط** (مقترح): جروح عميقة وبتر أصابع؛ إصابة دائمة لكن غير مهددة للحياة غالباً |
| الاحتمالية | **٣ — ممكن** (مقترح): جروح السكاكين شائعة أسبوعياً في المطابخ الكبيرة؛ البتر بالقطّاعة أقل |
| الدرجة | **٩ — عالٍ** |
| المرجع القانوني | OSHA 1910.212 كمرجع؛ ISO 12100؛ نظام العمل م١٢٢ و١٤٢؛ لائحة الاشتراطات الصحية للمطاعم (سلامة العاملين)؛ دليل المصنّع للمعدات |
| الفائدة من التوثيق | المطبخ عقد تشغيل وإصاباته لا تصل للمعهد؛ التوثيق يشترط الواقيات والتدريب وإبلاغ الإصابات ويضعها في تفتيش المطعم مع النظافة |
| قناة الاتصال | مركز السلامة (المناوب) — مشرف المطعم بحسب العقد |

### الطبقة الاستباقية — قبل الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب | **معدات ومواد:** قطّاعات بلا واقٍ أو بواقٍ مخلوع، لا دافع طعام، سكاكين كليلة (تحتاج قوة فتنزلق)، لا قفازات مقاومة للقطع. **تدريب وكفاءة:** عمال جدد بلا تدريب على المعدة. **تنظيمية:** لا إجراء تنظيف (فصل قبل التنظيف)، عقد بلا شرط سلامة. **سلوكية:** دفع الطعام باليد، التقاط سكين ساقط، الاستعجال في الذروة. **بيئية:** أسطح مبللة، ضوء ضعيف |
| العواقب والأضرار | الموظفون — ١ طفيف · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٣ متوسط** (عمال المطبخ) · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ١ طفيف · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ١ طفيف · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٢ بسيط |
| الإجراء الوقائي | (١) شرط في عقد التشغيل: معدات بواقيات المصنّع ودافعات طعام، قفازات مقاومة للقطع، سكاكين حادة ومكان حفظها، تدريب كل عامل على كل معدة قبل استخدامها بسجل، وإبلاغ المعهد بكل إصابة. (٢) إجراء التنظيف: فصل القابس قبل تنظيف أو فك أي معدة، وإعادة الواقي قبل التشغيل **(بحسب OSHA 1910.212)**. (٣) قواعد المطبخ: لا دفع باليد، لا التقاط سكين ساقط، القطع على لوح ثابت، لا سكاكين في حوض الغسيل. (٤) حقيبة إسعاف في المطبخ بضمادات ضاغطة، ومسعف مدرَّب في كل وردية (BI-06-04). (٥) بند «الواقيات والقفازات والتدريب» في تفتيش المطعم الدوري |
| الإجراء التصحيحي | عند معدة بلا واقٍ: إيقافها حتى التركيب وإنذار تعاقدي. عند عامل غير مدرَّب على معدة: منع حتى التدريب. عند إصابة لم تُبلَّغ: إنذار |
| التقييم بعد الإجراءات | الواقيات والقفازات والتدريب تخفض الاحتمالية من ٣ إلى ١؛ الخطورة تبقى ٣. الدرجة المتبقية ≈ ٣ (منخفض) |
| الجهة والشخص | مدير المشغّل ومشرف المطعم بحسب العقد (المعدات والتدريب والقواعد) · ٢٠ مسؤول السلامة بالمعهد (شرط العقد والتفتيش) · ٤ طبيب المعهد (الإصابات) |

### الطبقة التشغيلية — أثناء العمل الطبيعي

| الخلية | المحتوى |
|---|---|
| الأسباب | **سلوكية:** عامل يزيل الواقي لسرعة القطع، ينظف القطّاعة موصولة، يدفع آخر قطعة بيده، لا يلبس القفاز. **تنظيمية:** ذروة الغداء، عامل جديد يحل محل غائب. **معدات ومواد:** سكين كليل، واقٍ مكسور. **بيئية:** أرضية وأسطح مبللة |
| العواقب والأضرار | الموظفون — ١ طفيف · المتدربون والزوار — ١ طفيف · المقاولون وعمالهم — **٣ متوسط** · الفريق الأولي للاستجابة — ١ طفيف · ذوو الإعاقة والحالات الخاصة — ١ طفيف · الممتلكات والأنظمة — ١ طفيف · استمرارية الأعمال — ١ طفيف · السمعة — ١ طفيف / محلي · الخسائر المالية والقانونية — ٢ بسيط |
| الإجراء الوقائي (الضوابط القائمة) | (١) الواقي والدافع في كل استخدام، والقفاز المقاوم للقطع عند القطّاعة والتنظيف. (٢) فصل القابس قبل التنظيف والفك. (٣) مشرف الوردية يتحقق من الواقيات صباحاً ومن أن العامل مدرَّب على معدته. (٤) شحذ السكاكين دورياً، وحفظها في مكانها. (٥) الإصابات ولو خفيفة تُسجَّل وتُبلَّغ للمعهد. (٦) بند تفتيش المطعم الأسبوعي |

### طبقة الاستجابة — عند وقوع الحدث

| الخلية | المحتوى |
|---|---|
| الأسباب (ما يفاقم الحدث) | **تدريب وكفاءة:** الحارس لا يعرف زر الطوارئ أو الفتح اليدوي فيبقى الشخص منحشراً. **تنظيمية:** بوابة ثقيلة تسقط على شخص ولا رافع. **اتصال وإشراف:** الانحشار ليلاً بلا حارس عند بوابة خلفية. **معدات ومواد:** الباب يعيد المحاولة ويضغط مجدداً |
| العواقب والأضرار | الموظفون — **٣ متوسط** (المصاب) · المتدربون والزوار — **٣ متوسط** · المقاولون وعمالهم — ٢ بسيط · الفريق الأولي للاستجابة — ٢ بسيط · ذوو الإعاقة والحالات الخاصة — **٣ متوسط** · الممتلكات والأنظمة — ٢ بسيط · استمرارية الأعمال — ١ طفيف · السمعة — ٢ بسيط / محلي · الخسائر المالية والقانونية — ٢ بسيط |
| الإجراء الوقائي (تسلسل الاستجابة) | (١) **اكتشاف:** شخص منحشر بباب أو بوابة، أو مصدوم، أو بوابة ساقطة على شخص. (٢) **تدخل أولي:** زر إيقاف الطوارئ أو فصل التيار عن الباب أو البوابة، الفتح اليدوي (تحرير القفل الميكانيكي)، عدم سحب المصاب بالقوة؛ بوابة ساقطة: رفعها بعدة أشخاص أو رافعة دون إسقاطها ثانية. (٣) **إنذار:** المركز ← المسعف والمنقذ ومدير المرافق، و**٩٩٧** عند انحشار شديد أو بوابة ساقطة أو فقدان وعي، و**٩٩٨** إن تعذر التحرير. (٤) **إسعاف:** كسور وكدمات ونزيف، جروح الزجاج، مراقبة الصدر عند الضغط. (٥) **احتواء:** إيقاف الباب أو البوابة عن الخدمة وحاجز، مدخل بديل. (٦) **استعادة:** فحص واعتماد الفني قبل إعادة التشغيل، تسجيل |
| الإجراء التصحيحي | تحقيق: الحساس والقوة والموقفات والصيانة ← إصلاح وتعديل العقد ← تسجيل (إصابة عمل أو زائر) ← تعميم على الحراس |
| التقييم بعد الإجراءات | الإيقاف الفوري والتحرير الصحيح يخفضان الخطورة الفعلية من ٣ إلى ٢؛ الاحتمالية لا تتأثر. **الدرجة المتبقية للكتاب ≈ ٢ (منخفض) بعد الطبقات الثلاث** |
| الجهة والشخص | ٥ أفراد الأمن المكلفون (الإيقاف والفتح اليدوي) · ٩ المسعف في المكان (الإسعاف) · ١٠ المنقذ (التحرير والرفع) · ٢١ مناوب مركز السلامة (الإنذار) · ٢ مدير المرافق والصيانة (الباب) · ٢٠ مسؤول السلامة بالمعهد (التحقيق) |
