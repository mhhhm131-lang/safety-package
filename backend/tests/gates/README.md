# بوابات المراحل — أدوات التشغيل على العنوان المنشور

ليست اختبارات PHPUnit. تُشغَّل يدوياً بعد النشر (`/build.txt` = رقم الإيداع):

- `gate2.py [BASE]` — بوابة المرحلة ٢ (المخاطر): مدير إدارة يفعّل خطراً من الكتاب ويسمّي مسؤوله ويُعتمد.
- `gate3.py [BASE]` — بوابة المرحلة ٣ (البلاغات): سيناريو السري كاملاً + الإحالة والربط العكسي من النموذج.
- `gate4.py [BASE]` — بوابة المرحلة ٤ (الطوارئ): تفعيل ← تنبيه الفريق الأولي من ملف المكان ← وصول (يدوي + مسح رمز) ← سيطرة ← انتهاء ← تقرير، ثم تمرين كامل. يحتاج نقطة تجمع (ينشئها إن لم توجد) ولا يحتاج طوابق.
- `gate5.py [BASE]` — بوابة المرحلة ٥ (إنترنت الأشياء): تسجيل لوحة إنذار محاكاة (webhook) ← إنذار موقّع HMAC بلا جلسة ← حالة طارئة خلال ثانية ← توقيع خاطئ/غائب/قديم 401 ← إنذار ثانٍ يُسجَّل في الحالة نفسها ← إنهاء ← حذف جهاز الاختبار.
- `gate6.py [BASE]` — بوابة المرحلة ٦ (المقاولون والعمال): مقاول يُسجَّل ← مستندان إلزاميان وتوثيق وملف ← ثقة ← مشروع في HZ-06 ← ربط ← التأهيل المسبق واللاحق ← حساب مقاول مربوط بالطرف يدخل بوابته ويسجّل عاملاً ويقدّمه ← الاعتماد حتى «مصرّح بالعمل» ← الكفاءة والمهن ← الأدوار. ينشئ حساب `g6.muqawil` (123456) ويعيد ربطه في كل تشغيل.
- `harness/*.html` — صفحات Edge headless (تُنسخ مؤقتاً إلى `public/` ثم تُحذف): `journey` القصة، `two` جهازان، `role` دور حساب حقيقي، `place` ملف المكان في اللوحة، `occ` شريط بلاغات الشاغلين في نموذج الفحص.

التشغيل: `PYTHONIOENCODING=utf-8 python gate3.py https://ipa-safety.onrender.com` (تحتاج `requests`). رمز CSRF يؤخذ من صفحة بعد الدخول لا قبله.
