# بوابات المراحل — أدوات التشغيل على العنوان المنشور

ليست اختبارات PHPUnit. تُشغَّل يدوياً بعد النشر (`/build.txt` = رقم الإيداع):

- `gate2.py [BASE]` — بوابة المرحلة ٢ (المخاطر): مدير إدارة يفعّل خطراً من الكتاب ويسمّي مسؤوله ويُعتمد.
- `gate3.py [BASE]` — بوابة المرحلة ٣ (البلاغات): سيناريو السري كاملاً + الإحالة والربط العكسي من النموذج.
- `harness/*.html` — صفحات Edge headless (تُنسخ مؤقتاً إلى `public/` ثم تُحذف): `journey` القصة، `two` جهازان، `role` دور حساب حقيقي، `place` ملف المكان في اللوحة، `occ` شريط بلاغات الشاغلين في نموذج الفحص.

التشغيل: `PYTHONIOENCODING=utf-8 python gate3.py https://ipa-safety.onrender.com` (تحتاج `requests`). رمز CSRF يؤخذ من صفحة بعد الدخول لا قبله.
